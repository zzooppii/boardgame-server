# Patchwork original artwork

`cover.svg` and the runtime SVG in `features/patchwork/art.tsx` are original vector illustrations created for this implementation. No external fonts, scanned components, publisher logos, screenshot crops or copied game assets are embedded. The supplied screenshot informed the wooden table, two quilts, textile tiles, buttons and central timeboard composition. Geometry and numerical component facts are documented in `docs/PATCHWORK_GAME_RULES.md`.

UI text and numerical labels remain DOM/SVG text. Sound is generated locally using Web Audio; no external recordings are loaded.
