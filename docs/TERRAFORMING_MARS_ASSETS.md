# 테라포밍 마스 시각·청각 자산

## 일러스트

내장 imagegen으로 별도 제작한 오리지널 일러스트다. 첨부 화면의 카드 그림이나 보드 이미지를 복제하지 않았다. 생성 PNG를 육안 검수한 뒤 WebP로 최적화했다.

- `apps/web/public/images/mars/terrain.webp`: 1254×1254, 화성 지도와 대기실 행성.
- `apps/web/public/images/mars/cards-atlas.webp`: 1448×1086, 4열×3행 프로젝트·기업 일러스트. UI에서 태그별로 해당 장면을 사용한다.
- 원본 생성 결과는 로컬 `.codex/generated_images/01a0a594-5bf8-7761-b7a3-5ec9c70fca42/`에 있으며 제품은 위 WebP만 참조한다.

### 생성 브리프 / 프롬프트 구성

1. 행성 지형: 정사각형, 위에서 내려다본 황토·테라코타색 화성 지표, 중앙의 넓은 협곡, 왼쪽 위 화산, 보드 배경에 어울리는 일러스트. 격자·문자·UI를 제외하여 SVG 배치 칸과 보너스가 읽히도록 구성.
2. 카드 장면: 동일한 크기의 4×3 패널, 패널 간 틈과 문자가 없는 SF 보드게임 일러스트. 행 순서로 도시·온실·호수·소행성, 채굴 로버·궤도 정거장·태양광·지열 발전, 미생물 연구실·동물 서식지·기업 본사·관측소.

도시·녹지·해양 타일은 직접 작성한 SVG로 확대 시 선명도를 유지한다. 소유권은 색뿐 아니라 플레이어 번호로도 표현한다.

## 소리와 상호작용

Web Audio로 선택·카드·타일·해양·녹지·열·생산·내 차례·선점·종료·오류를 구분하는 짧은 효과음을 합성한다. 외부 음원과 새 의존성은 없다. 첫 사용자 입력으로 오디오를 활성화하고 음량·음소거를 로컬에 저장한다. 첫 로드·중복 스냅샷·재접속·누락된 중간 리비전에서는 과거 효과음을 재생하지 않는다.

지도 후보 선택 → 설명 확인 → 배치 확정, 카드 선택 → 비용·효과 확인 → 지불 확정으로 조작한다. 지불 전 카드 선택은 취소할 수 있다. 키보드 Enter/Space와 배치 후보 목록을 제공하며, 좁은 화면에서는 세로 배치와 지도 확대를 사용한다. `prefers-reduced-motion` 설정을 따른다.
