## CONFIRMED · 기본판

- 2–5인, 색당 새 28마리, 5라운드. 2인에서는 점수를 얻지 않는 중립 색을 추가한다.
- 2–3인 8장(기본3/특수2/동물3), 4인 10장(4/2/4), 5인 13장(5/3/5). 열 길이는 3-2-3 / 2-3-2-3 / 3-2-3-2-3. 인접 관계는 엇갈린 열을 따른다. 올빼미 헛간은 바깥 가장자리.
- 목표는 인원에 맞는 카드 중 2장을 받아 1장 선택. 첫 게임에서는 목표를 생략할 수 있다.
- 이동 시 색마다 2마리를 주머니에 넣는다. 중립은 첫 라운드 4, 이후 2마리. 모집은 자기 공급처 2마리와 주머니 2마리. 공급처 부족 시 가능한 만큼만 사용.
- 차례마다 모집한 새 1마리를 배치하고 보너스는 최대 1회, 전후 순서 자유. 같은 장소·같은 색은 하나의 무리. 둥지와 새집은 해당 무리의 유효 새 수에 각각 +1.
- 새집이 덮인 무리는 추가·제거·동물·번개에 영향받지 않는다. 새집은 4라운드, 번개는 5라운드에 지급. 번개는 빈 둥지를 제거할 수도 있다.
- 장소 자체가 제거되는 ‘과밀 새집’ 효과는 카드와 규칙서 8쪽 제거 FAQ를 우선한다. 해당 새들은 광장(중립은 공급처), 둥지·새집은 회수, 동물은 본거지로 돌아간다.
- 동물은 정비 때 본거지의 단독 지배자가 획득하며 라운드당 1회 활성화. 이동은 필수, 효과는 선택. 동률이면 조종자 없음. 허수아비는 조종자 변경 때 교차점을 변경하며 일반 이동을 하지 않는다.
- 분수 자리 수: 2–3인 아래부터 4/3/2/2/1개, 4–5인 4/4/4/3/2/1개. 각 연결선의 받침 관계를 원본 보드와 대조한다.
- 분수는 영향을 받은 새의 주인이 놓는다. 중립 새는 효과를 일으킨 플레이어가 선택. 연결된 아래 자리가 모두 차 있어야 하며 꽉 차면 광장으로 간다. 다람쥐 카드의 교환은 일반적인 이동 금지보다 우선한다.
- 정산은 왼쪽 열부터 위→아래. 동률 순위는 모두 0점이며 다음 플레이어의 순위를 끌어올리지 않는다. 새는 정산 후 남는다.
- 점수가 높은 사람부터 다음 라운드 차례. 같은 점수에 먼저 도착한 사람이 우선. 높은 횃대 지배자는 마지막. 이후 장소 정비 효과를 열 순서대로 처리한다.
- 종료: 5라운드 정비 완료 → 주머니 잔여 새를 광장으로 → 개인 목표 → 최대 단일 무리 10점(동률 취소), 동물당3점, 분수 층별 점수, 광장 새당1점. 승점 동률이면 최대 무리, 분수 새 수, 공동 승리 순.
- 중립 색은 장소 효과 혜택과 점수를 받지 않으나 순위·동률에는 참여한다. 장소 효과가 중립 새를 분수/광장으로 보내면 공급처로 돌려놓는다. 동물/번개는 일반 분수 규칙을 따른다.
- 장소 24종, 동물 9종, 목표 22종의 한국어 요약과 수치는 `packages/shared/src/games/perch/catalog.ts`에 정의한다.

## CONFIRMED · 온라인 구현 정책

- 이전 설계 제안에 대한 개발 승인에 따라 강제 턴 제한시간 없음. 연결 단절 시 현재 상태·선택권 보존. 명시적 퇴장은 게임 취소(정상 승자 없음); 대기실 복귀와 재시작은 기존 방 기능 이용.
- 첫 차례는 주입 난수로 정한다. 초기 추천 배치/무작위 배치와 목표 사용 여부는 방장이 게임 준비 화면에서 설정한다.
- 모집한 새와 공급처의 색별 남은 개수는 공개. 주머니 내부 순서·식별자와 다른 사람의 목표/선택 후보는 비공개. 목표 선택 결과는 선택 완료 여부만 전파한다.
- 효과 중 추가 선택은 `pending`과 처리 큐로 보존한다. 일반 턴 소유자와 현재 응답자를 분리하며, 다단계 선택 각각은 검증된 원자적 전이로 저장한다.
- 이동의 한 칸은 6방향 인접 칸. 장소 제거로 생긴 빈칸을 건너뛰지 않는다. 보드 밖 또는 제거된 칸으로 밀려난 새는 분수로 간다. 올빼미는 남은 바깥 경계 장소의 시계 방향 순서를 사용한다.
- 필수 효과에 적법한 대상이 부족하면 가능한 부분만 처리하고 다음 효과로 진행한다. 보너스 효과의 자발적 생략은 효과 시작 전에 선택한다. 효과를 시작한 후에는 가능한 남은 부분을 처리한다.
- 무리 단위 새 교환도 각 입출구의 새집 보호와 색별 합류를 검증하며 빈 둥지로의 자동 이동은 하지 않는다. 빈 둥지 차지는 배치 행동에서 명시적으로 선택한다.
- 점수 도착 순서는 서버의 점수 트랙 스택으로 기록한다. 정비의 한 장소에서 여러 색이 동시에 득점하면 현재 차례 순으로 반영한다.
