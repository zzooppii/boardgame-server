> Use case: stylized-concept. Create an original production sprite atlas for a gothic multiplayer horror board game. Each portrait centered chest up with face around center and generous room around head. BOTTOM LEFT: Spectre, a terrifying translucent female apparition with long drifting raven hair, pale ghostly face, ethereal tattered mourning dress, blue-violet mist, no gore. BOTTOM RIGHT: Murderer, a sinister masked human stalker in dark hooded raincoat with a glinting slender blade at waist, face obscured, green moonlit fog, no gore. Rich detailed painted illustration, cinematic chiaroscuro, blackened teal backgrounds, copper accents. Distinct original designs, not copied from any published board game artwork. These four cells must remain cleanly separate. No logos, lettering, watermark.
