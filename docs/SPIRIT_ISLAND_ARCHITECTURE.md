# 정령섬 구현 경계

[규칙과 범위](./SPIRIT_ISLAND_GAME_RULES.md)를 따른다. 기존 Room/Session/UoW/Socket.IO 경계를 유지한다.

- `packages/shared/src/games/spirit-island`: 공개 정령·카드 메타데이터, 지도 연결, strict command와 projection 계약.
- `apps/server/src/games/spirit-island/domain`: framework-independent 상태·전이·효과 처리. 전부 candidate에서 검증 후 commit한다. 선택을 요구하는 효과를 직렬화 가능한 대기 상태로 보존한다.
- `application`: 인증된 actor, 현재 세션, 방 직렬화, request receipt와 원자 commit. 타이머 없음.
- `compatibility`: 저장 상태 검증 및 명시적 allowlist projection. 미공개 카드 후보와 덱 순서는 보호한다.
- `apps/web/src/features/spirit-island`: 실제 지도·기물, 정령/카드 패널, 선택·확정, 협동 안내, 반응형 레이아웃, Web Audio 효과음.
- 새 dependency·서버 설정·배포 변경 없음. 기존 게임에 정령섬 규칙을 섞지 않는다.

검증은 도메인 규칙·위조 입력·실제 Socket.IO 다중 접속·재접속·브라우저 상호작용과 root typecheck/test/build 및 diff 검사를 포함한다. 완료 결과와 실제 제한은 후속 검증 기록에 남긴다.

## 검증 기록 — 2026-09-13

- root `npm run typecheck`, `npm test`, `npm run build` 실행. 전체 회귀 테스트 3,185개 통과(shared 131 / web 688 / server 2,211 / e2e 155). 이후 추가한 1–4인 종료까지의 진행 검증을 포함한 정령섬 도메인 테스트 139개도 별도로 전부 통과했다.
- 정령섬 Socket.IO 테스트: 1–4인 시작, 5인 시작 거부, 같은 방 게임 교체, deadline 없음, 중복·경쟁 요청, request fingerprint, stale revision, 불법 입력의 무변경, 선택 중 재접속, 명시적 나가기 취소와 재시작.
- 브라우저: 실제 방 생성·정령 선택·성장·트랙/현신 배치·카드 비용 확정·빠른 능력 대상 지정·피해 대상 선택·탐험가 제거·새로고침 복원. 390×844 모바일과 데스크톱에서 확인했고 브라우저 error 로그는 없었다.
- `git diff --check` 통과. 빌드는 성공하지만 기존 단일 JS 번들의 500 kB 초과 경고가 남는다(약 1.59 MB, gzip 약 447 kB). 번들 분리는 이번 기능 범위에서 다루지 않았다.

## 화면과 조작

공개 카드와 정령의 기능 설명은 독자적으로 작성한 한국어 설명이다. 전용 생성 일러스트는 [이미지 기록](../apps/web/public/images/spirit-island/README.md)을 참조한다. SVG 기물과 지형 표식, 지형별 색, 위험 표시, 대상 강조를 함께 사용한다. 지도는 공간 배치를 단순화한 디지털 표현이며 인접 연결선과 상세 목록이 이동·사거리 판단 기준이다.

동료 행동으로 game revision이 바뀌어도 내 임시 손패 선택은 유지한다. 카드 준비와 단계 완료는 별도로 확정한다. 피해·이동·현신·획득 후보는 서버가 전달한 가능한 선택 중에서 고른 뒤 확정하며, 늦은 응답은 이전 화면을 덮어쓰지 않는다. 음량은 로컬 저장하고 첫 snapshot과 재접속 때 지난 소리를 재생하지 않는다.

공개 배포와 서버 재시작 후 영구 복원은 포함하지 않았다. 나머지 정령·대적·시나리오·오염 카드·확장은 규칙 문서의 후속 범위다.

## 기본판 콘텐츠 후속 개발 — 2026-09-13

사용자 승인 범위는 기본판과 플레이 완성도이며 저장·서비스 운영·확장팩·관전·AI는 제외한다. 위 첫 버전의 미구현 목록은 이 절과 최신 규칙 문서로 대체한다.

- 규칙 계약 버전은 `spirit-island-core-v2`다. 서버 상태·공개 projection·타이머 제외 판정을 함께 변경했다.
- 공유 `settings.ts`: 설정 DTO·기본값·대적/시나리오 표시명·공포 덱 구성. `CONFIGURE`는 정령 선택 전 첫 플레이어만 1회 실행한다. `TRACK_ELEMENT`, `RITUAL`도 기존 인증·revision·직렬화 경계를 따른다.
- 서버 `domain/settings.ts`: 대적 초기 배치와 덱 편성, 시나리오 준비, 의식 자격 검사. `resolver`는 오염 카드·강화·익사·현신 동행·악몽·다한 봉기 및 의식 기여를 선택 큐로 처리한다.
- 원소 트랙과 두 번째 고유 능력을 지원한다. 바다 지역은 번호 0으로 구분하고 일반 침략자의 대상에서 제외한다. 공개 projection은 숨겨진 오염 카드와 전체 덱을 보내지 않으며 공개된 공포 위치/이름/효과 설명만 추가한다.
- 웹 `SettingsPanel.tsx`는 설정 선택, `presentation.ts`는 공개 상태 기반 표시 보조와 카드 일러스트 테마 배정이다. 서버가 가능한 능력/선택을 결정한다. 표시 계산은 명령 판정에 사용하지 않는다.
- 새 섬/능력 일러스트와 정령별 음색을 기존 화면에 통합한다. 카드 90장마다 독립 이미지 파일이 있는 구조는 아니며 16개의 그림을 카드 효과에 맞춰 배정한다. 인접 그래프와 위험 표식을 배경 그림보다 우선한다.
- 기존 dependency·저장소·배포 설정 변경 없음. 추가 검증 결과는 개발 완료 시 기록한다.

## 가지와 발톱 첫 구현 — 진행 중

사용자의 후속 승인으로 가지와 발톱을 범위에 추가했다. 저장·운영·관전·AI는 계속 제외한다. 기본판 완료 기록은 위 검증 시점의 기록이며 확장 완성을 의미하지 않는다.

- `settings.expansion`은 기본판과 가지와 발톱 개발판을 구분한다. 개발판은 정령 2종·고유 능력 8장·토큰만 체험 가능하며 설정 화면에 미포함 콘텐츠를 명시한다. 기존 공용 덱으로 플레이하므로 정식 확장 규칙을 완성한 모드가 아니다.
- `domain/tokens.ts`는 지역 토큰의 선택·이동과 야수 동행을 처리한다. 분쟁은 침략자 인스턴스에 붙으며 이동·침략자 교체 시 보존한다. 탐험·건설·파괴의 토큰 소비는 `resolver.ts`에서 서버 판정한다.
- `domain/branch-claw.ts`는 새 정령의 고유 능력과 추가 효과를 기존 효과 큐에 연결한다. 성장 2회, 선불 비용, 현신 영구 제거, 성소 생성 시 다한 밀기를 기존 인증·원자적 검증 경계 안에서 처리한다.
- 공개 projection은 성장 선택 기록, 회수 기록, 야수 부르기 가능 여부와 토큰 수를 제공한다. 클라이언트는 이를 표시하며 유효성 판정은 서버에서 재검증한다.
- 남은 확장 구현: 보조 31장·주요 21장, 일반 이벤트 25장·프랑스 전용 이벤트, 공포 15장·오염 7장, 프랑스 대적 0–6단계, 시나리오 4종. 이벤트 지원 비용과 위 콘텐츠 조합 검증도 미완료다.

## 가지와 발톱 보조 능력 31장 — 후속 구현

- 기존 개발판은 `302853f`에 커밋했다. 이번 후속 변경은 확장 보조 능력 31장을 추가한다. 기본판 36장과 함께 확장 모드 보조 덱은 67장이다. 기본판 모드에서는 확장 카드를 덱에 넣지 않는다.
- 공유 `branch-claw-powers.ts`는 카드의 규칙 사실과 한국어 표시 정보를 제공한다. 서버 `branch-claw-minor.ts`는 선택 분기, 지연 효과, 대상 정령의 추가 카드 준비를 기존 효과 큐로 처리한다.
- 오염 이동은 오염 추가와 구별한다. 새 기물 추가와 교체도 구별하여 안개의 이동 효과가 교체에 반응하지 않게 한다. 공포 추가 효과는 실제 파괴 때만 한 번 발생한다. 파괴→건설 변환에도 질병·정령·공포의 건설 차단을 적용한다.
- 속도 변경권은 빠름→느림과 느림→빠름 중 한 번에 소비한다. 해안 사거리 보너스와 지연 효과는 시간의 흐름에 초기화된다. 추가 카드 준비는 대상 정령에게 비용을 청구하고 원소를 제공하며 준비 완료 상태를 해제한다.
- UI는 카드의 대상 지형·조건과 사거리 출발 지형을 표시한다. 새 동물 계열 카드는 기존 동물 일러스트 테마를 사용하며, 분쟁 선택지는 침략자의 피해와 현재 분쟁 수를 함께 표시한다. 새로운 dependency·저장·운영·관전·AI 변경은 없다.
- 현재 남은 확장 범위: 주요 능력 21장, 이벤트 25장과 프랑스 전용 이벤트, 공포 15장·오염 7장, 프랑스 0–6단계, 시나리오 4종. 개발판 안내를 유지한다.

- `branch-claw-farmer-events.ts`는 비용 없는 두 대응을 새 DECISION 카탈로그 유형으로 제공한다. 거절은 보드별 다한 피해·오염 후 건물 체력을 낮추고, 가르침은 보드별 마을 추가 후 다음 정상 파괴를 건설로 바꾼다. 두 대응 모두 새 질병을 해결하며 별도 다한 항목은 없다.
- 다음 정상 파괴 전환은 서버 대기 플래그로 라운드 간 보존한다. 실제 파괴 카드가 있으면 공통 건설 큐로 처리하고 종료 시 해제한다. 빈 카드와 추가 파괴는 소모하지 않으며, 다음 정상 파괴 피해 증가도 건설로 전환된 카드에서는 계속 대기한다. 질병·건설 생략·잉글랜드 인접 건설 조건을 재사용한다.
- 공개 `eventRavageToBuild`와 지역별 `eventBuildingHealthLoss`로 이벤트 패널·지도·선택 지역 미리보기를 동기화한다. 기존 일러스트·선택 UI·공개 효과음을 재사용한다.
- 일반 이벤트 19/25장. 남은 일반 이벤트 6장, 프랑스 전용 이벤트·대적, 공포 15장·오염 7장·확장 시나리오 4종은 미완료다.
