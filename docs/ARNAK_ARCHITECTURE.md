# Arnak 구현

기존 게임별 domain/application/compatibility 경계를 따른다. room의 기존 인증·직렬 실행·멱등성·재접속을 재사용한다.

서버가 현재 상태에서 가능한 행동 목록을 생성한다. 클라이언트는 선택한 행동 ID와 gameRevision/turnId를 보낸다. 서버는 현재 목록을 다시 생성해 검증한 뒤 복제 상태에 적용하고 한 번에 저장한다. 비용 선택과 중간 효과 선택도 동일한 방식이다.

비공개 손패와 덱은 서버에 보관한다. 상대방 projection에는 개수만 공개하고 본인에게만 손패와 행동 목록을 보낸다. 발견 전 장소·수호자·덱 순서는 전송하지 않는다.

화면은 중앙 탐험 섬, 오른쪽 연구 트랙, 상단 시장, 하단 개인 캠프와 손패로 구성한다. 일러스트는 새로 생성한 island/camp/atlas를 사용하며, 소리는 사용자 입력 이후 Web Audio로 합성한다. 음소거와 모션 감소 설정을 존중한다.

## 검증 범위

- 기본판 75장 각각 사용 및 중간 효과 해소, 카드 인스턴스 보존.
- 2·3·4인, 고정 난수 4개씩 총 12개 대국의 5라운드 종료.
- 위조 행동, 차례 위반, 오래된 revision, 멱등 재전송, 재접속 후 선택 복구, 상대 손패와 덱 비공개.
- 데스크톱 실제 배치 조작 및 390px 모바일에서 문서 가로 넘침 없음 확인.

이는 자동화된 규칙·상태 검증이며 모든 카드 조합의 플레이테스트를 대체하지 않는다. 확장은 아직 구현하지 않았다. 초판 카드 이름 번역과 테마 일러스트는 원작과 차이가 있다.
