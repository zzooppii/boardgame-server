# 팬데믹 기본판 규칙과 온라인 진행

상태: 기본판 구현 완료. 2026-09-14 사용자가 기본판 개발 및 일러스트·UI·소리·조작을 승인했다.
규칙 출처: [Z-Man/Asmodee 기본판 2013 규칙서](https://cdn.svc.asmodee.net/production-zman/uploads/2024/09/Pandemic_Rulebook.pdf). 첨부 화면은 분위기·배치 참고이며 화면 속 진행 수치나 안내는 구현 지시가 아니다.

## CONFIRMED

- 기본판 48도시, 4색 각24큐브, 연구소6개, 7역할, 5이벤트. 2–4인 협동.
- 초기 애틀랜타 연구소/말, 3도시씩3·2·1큐브. 초기 감염에는 검역 능력 미적용.
- 초기 손패 2인4/3인3/4인2장. 도시 인구 최댓값 보유자가 선. 동률은 좌석 순서(온라인 결정).
- 최대4행동 → 카드2장 → 전염병 해결/손패7장 → 감염률만큼 감염. 도시별 색마다 최대3큐브. 카드 하나의 발병 연쇄에서 도시 중복 발병 방지.
- 치료제4종 즉시 공동 승리. 8번째 발병, 필요한 큐브 부족, 뽑아야 할 플레이어 카드2장 부족 시 즉시 공동 패배. 치료와 박멸은 구분한다.
- 전염병4/5/6장으로 덱을 균등 분할해 각각 한 장을 섞고 작은 더미를 아래에 둔다. 강화는 감염 버림패만 섞어 덱 위에 올린다.
- 7역할의 예외, 정부 보조금/공중 수송/예측/저항력 강화/하룻밤의 평온을 포함한다. 위기관리자가 보관한 이벤트는 손패 제한 제외, 사용 시 제거.
- 기본 설정은 입문4장·공개 손패. 시작 전 방장이 난이도와 손패 공개를 설정할 수 있다. 이는 공식 규칙서가 허용하는 공개 손패 합의 방식이다. 비공개 손패 모드도 덱/손패 projection을 서버에서 제한한다. 비공개 손패에서 받기는 먼저 요청하고, 카드 소유자가 합법적인 카드 한 장을 골라 동의한다.
- 연구소 초과 건설 시 이전할 연구소를 선택한다. 지식 공유·타인 이동은 상대 동의를 서버 대기 상태로 보관하고 승인 시 비용과 결과를 함께 반영한다. 거절은 비용 없음.
- 이벤트는 합법적인 처리 경계에서 사용. 카드 공개와 그 카드의 감염/연쇄는 원자 처리. 전염병 감염과 강화 사이에는 저항력 강화 등 개입 가능. 예측 중에는 지정 플레이어만 덱 위 카드를 본다.
- 강제 턴 타이머 없음. 자동 단계는 팀원 모두가 이벤트 없이 계속 진행에 동의하면 진행한다. 이벤트 사용이나 선택 해결 후에는 진행 동의를 초기화한다. 이벤트 소유자는 각 경계에서 사용할 수 있으며 시간 초과로 기회를 소멸시키지 않는다. 실시간 협의는 핑과 행동 기록을 보조로 사용한다.
- 새로고침/일시 단절은 재접속하여 대기 선택을 복원. 명시적 방 나가기는 게임 취소(승패 아님). 방 유지·다시하기는 기존 플랫폼 경계 활용.

## TO_BE_CONFIRMED / 후속 범위

확장팩, AI, 관전, 서버 재시작 후 영구 저장, 공개 배포는 이번 구현 범위에 포함하지 않는다. 단절 동안 다른 사람의 차례를 대신 진행하는 기능은 없다.
