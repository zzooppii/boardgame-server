# 아르낙의 잊혀진 유적 — 기본판 구현 기준

## CONFIRMED

사용자 요청에 따라 기본판 새 사원, 2–4인, 5라운드 규칙을 구현한다. 확장은 후속 선택 사항이다. 서버가 모든 비용, 선택, 무작위 순서와 점수를 판정한다. 제한 시간은 사용하지 않는다.

- 시작 덱: 자금 지원 2장, 탐험 2장, 공포 2장. 라운드 시작 손패 5장. 시작 자원은 순서대로 금화2 / 금화1·나침반1 / 금화2·나침반1 / 금화1·나침반2.
- 매 차례 주 행동 하나와 가능한 자유 행동. 패스하면 그 라운드에 다시 행동하지 않는다.
- 일꾼 배치에는 이동 비용을 지불한다. 발견 비용은 1단계 나침반3, 2단계 나침반6. 비행기는 모든 이동을 대신하고 금화2로 비행기1을 지불할 수 있다.
- 아이템은 덱 아래로, 유물은 구매 즉시 효과를 적용한다. 손패 유물 사용은 석판1을 추가로 지불한다.
- 라운드 종료 시 수호자와 함께 있는 일꾼마다 공포1. 남길 손패를 선택하고 사용한 카드를 섞어 덱 아래에 놓는다.
- 돋보기보다 높은 행에 수첩을 올릴 수 없다. 수호자5점, 우상3점, 미사용 우상 슬롯1·2·3·4점. 공포 카드는 -1점, 공포 대체 타일 -2점.
- 기본판 아이템40장·유물35장. 돌 열쇠는 원본 0229를 사용하며 확장 교체 카드1208은 섞지 않는다.

## 미확정 / 후속 범위

탐험대장, 사라진 탐험대, 뱀 사원, 솔로 모드는 이번 기본판 범위 밖이다. 한국어 카드 이름은 화면용 번역이며 공식 한국어판 용어와 최종 대조가 필요하다.

## 기본판 세부 규칙 확인 — 2026-09-16

기존 CONFIRMED 기본판 규칙을 공식 영어 규칙서의 카드 열 보충, 조수 고용, 카드별 설명과 대조했다.

- 교역소 보충은 차례 종료 시 수행한다. 유물 효과를 처리하는 중에는 새 카드가 나타나지 않는다. 새 유물은 열의 바깥쪽(화면 왼쪽), 아이템은 오른쪽에 들어온다. 한 종류의 덱이 소진되어도 다른 종류로 빈자리를 대체하지 않는다.
- 아라아누의 우상·문자가 새겨진 칼의 연구 할인은 사원 도착 후 사원 타일 획득에도 적용한다. 수첩 전용 탐사 일지는 사원 타일을 얻을 수 없다.
- 조수 공급 더미는 맨 위 조수만 공개한다. 나머지 순서는 서버에만 남긴다.
