# 프렐류드 원판 구현

## 범위와 사용 방법

로비의 방장이 기업시대와 프렐류드를 독립적으로 선택한다. 두 옵션은 기본값이 꺼짐이며 시작 후에는 고정된다. 프렐류드 원판 35장, 프로젝트 7장, 기업 5종을 구현했다. 프렐류드 2·추가 지도·솔로·드래프트·영구 대국 저장은 포함하지 않는다.

| 기업시대 | 프렐류드 | 프로젝트 | 일반 기업 | 기본 생산량 |
| --- | --- | --- | --- | --- |
| 끔 | 끔 | 137 | 10 | 각 1 |
| 켬 | 끔 | 208 | 12 | 각 0 |
| 끔 | 켬 | 144 | 15 | 각 1 |
| 켬 | 켬 | 215 | 17 | 각 0 |

초보자 기업은 별도다. 프렐류드를 켜면 기업·프로젝트와 함께 각자 받은 프렐류드 4장 중 2장을 무료로 선택한다. 초기 프로젝트 구매는 프렐류드 수입을 받기 전에 처리한다. 모든 참가자가 확정하면 시작 플레이어부터 자기 2장을 순서대로 실행한 다음 일반 행동을 시작한다.

## 서버와 공개 계약

- `prelude.ts`에는 카드의 인쇄 정보와 이 프로젝트의 효과 정의를 둔다. 프로젝트 덱은 `marsProjectCatalog`, 기업은 `marsCorporationCatalog`로 선택한다. `marsCard` 조회에는 공개된 프렐류드도 포함한다.
- `mars:configure`에 `prelude` 옵션을 추가했다. 방장·로비·room revision·중복 요청 검증과 기존 방 직렬화 경계를 유지한다. 저장소는 설정과 실행 상태의 변형이 일치하는지 검증한다.
- 상태 단계는 `SETUP → PRELUDE → ACTION`이며 이후 연구·생산 흐름은 기존과 같다. 선택한 두 장의 순서는 실행할 때 정한다. 프렐류드는 일반 행동 수를 소비하지 않는다. 밸리 트러스트의 추가 프렐류드 선택·실행은 기업 첫 행동 하나로 처리한다.
- 프렐류드 덱·버림·재고와 플레이어의 비공개 후보를 프로젝트와 구분해 보존한다. 서버는 35개 고유 인스턴스의 보존을 검사하며, 다른 참가자의 후보·선택한 미실행 카드·덱 식별자를 projection에 넣지 않는다.
- `SETUP.preludeIds`는 활성 대국에서 자기 후보 중 서로 다른 2장이어야 한다. 실행·환급·지불·선택 대기는 기존 revision과 idempotency로 검증한다. 서버 실행 중 새로고침·재접속으로 복원한다.
- `drawTag`는 카드를 공개하면서 필요한 태그 2장을 찾고 나머지를 버린다. 덱과 버림의 현재 재고를 한 번만 훑도록 제한한다.
- `instantProject`는 괴짜 후원자의 25 M€ 할인 또는 생태학 전문가 그룹의 전역 조건 무시를 단일 프로젝트에 한정한다. 지불 취소는 선택 단계로 돌아가며, 이후 카드로 효과를 넘기지 않는다. 서버 projection의 표시 가격도 이 할인을 반영한다.
- `PAY.payment.microbes`는 호냉성 미생물의 자원을 사용한다. 서버가 자기 카드·보유 수량·식물 태그·지불 가치를 검증한다. 생산량이나 일반 프로젝트에는 사용할 수 없다.
- 와일드 태그는 자신의 조건·태그별 효과·업적에서만 사용하고 다중 조건에서 중복 배정하지 않는다. 상대 태그 참조·태그 반응·기업상·최종 점수에는 제외한다. 밸리 트러스트 할인은 새 카드에 인쇄된 과학 태그 개수만큼 적용한다.

## 화면·일러스트·소리

- 로비에서 두 옵션, 현재 덱·기업 수와 시작 생산량을 표시한다. 참가자는 읽기만 가능하다.
- 프렐류드 선택은 2/2 카운터, 보라색 테두리, 선택 제한, 키보드 조작을 제공한다. 한국어 제목과 영어 제목을 함께 표시한다.
- 기존 오리지널 일러스트에서 도시·해양·생태·우주·소행성·열·연구·금융 등 카드 효과에 맞는 장면을 배정했다. 새 개별 카드 그림을 생성한 것은 아니다.
- 프렐류드 실행 순서, 실행 불가 환급, 즉시 프로젝트와 비토르의 첫 무료 기업상 선택을 안내한다. 미생물 지불은 서버가 허용한 경우에만 수량 입력을 표시한다.
- 효과음을 공통 음량 노드에 연결해 이미 재생 중인 소리에도 음소거를 적용한다. 80ms 이내의 반복 선택음은 겹쳐 재생하지 않는다.

## 한국어·실사용 검수

[한국어 표시명 표](TERRAFORMING_MARS_KOREAN_NAMES.md)에 프로젝트·프렐류드·기업의 이름을 기록했다. 공개 한국어 자료와 대조했으며 공식 한국어판 실물 대조는 남아 있다. 사람이 참여하는 장기 대국, 실제 휴대폰/Safari/iOS/Android 조작, 스피커·이어폰 청음은 자동 검증과 구분한다.

## 재실행

```sh
npm run typecheck
npm test
npm run build
PLAYWRIGHT_MODULE=/path/to/playwright MARS_CHROME_PATH='/path/to/Chrome' node --test e2e/mars-prelude.browser.test.mjs
```

브라우저 검증은 격리된 로컬 서버와 두 세션을 사용한다. 실제 로비 설정, 비공개 2/4 선택, 키보드, 320px 화면, 재접속, 프렐류드 실행에서 일반 행동으로 전환, 음소거 시 오디오 gain 감소를 확인한다. 별도의 운영용 디버그 경로나 의존성은 추가하지 않았다.

## 검증 기록 (2026-09-16)

- 프렐류드 35장과 프로젝트 7장의 실제 실행, 추가 기업 5종, 중복 과학 태그 할인, 즉시 프로젝트 할인 취소·소비, 와일드 다중 조건과 종료 점수 제외, 미생물 지불·초과 수량 거절을 테스트했다.
- 기본판/기업시대에 프렐류드를 각각 더한 2–5인 대국 8개를 실제 Socket.IO 클라이언트로 최종 정산까지 완료했다. 초기 동시 선택의 stale revision 재시도, 선택 대기 재접속, 미실행 후보 비공개와 프렐류드 중복 실행 방지를 확인했다.
- 프렐류드 Chrome 검증 통과. 두 로비 옵션의 독립성·참가자 읽기 전용·새로고침 보존, 2/4 선택 제한·키보드, 320px 화면, 실행 완료 후 행동 수 0과 시작 플레이어 복원, 음소거 시 실제 출력 gain 감소를 확인했다. 로비와 모바일 선택 스크린샷도 직접 검토했다.
- 기본판과 기업시대의 비공개 카드 선택·교환·지불·공격·복제·배치 Chrome 회귀가 각각 통과했다. 한글 명칭 변경에 따른 기존 기대값(물고기·돔 크레이터·지하수 개발)과 서버 반영 전에 즉시 체크 상태를 단정하던 테스트를 갱신했다.
- 최초 전체 테스트는 새 테스트의 중복 import로 웹 컴파일이 중단되어 수정 후 재실행했다. 초기 도메인·브라우저 검증에서 나온 이전 이름 선택자도 실제 표시명에 맞춰 수정하고 재검증했다. 실패한 최초 실행을 성공으로 재분류하지 않는다.
- 타입 검사와 빌드 통과. 기존 공통 번들 500 kB 경고는 유지된다. 의존성과 영구 대국 저장은 추가하지 않았다.
- 최종 루트 `npm test` 전체 통과: 공유 145개·웹 985개·서버 4,139개·공통 E2E 155개, 총 5,424개. 최종 실행의 실패·미실행 테스트는 0개다.
- 추가 기본판 Chrome smoke도 통과했다: 손패 검색·정렬, stale 선택 오류 복구, 모바일 바로가기·44px 터치 영역, 키보드 해양 배치, 새로고침, 효과음 생성·음소거 저장. 첫 시도는 병행 빌드의 CSS 교체로 자산 preload가 실패했으며, 최종 빌드의 임시 복사본을 `webDistPath`로 제공한 재실행에서 통과했다.
- 최종 표시명·게임 목록 설명을 포함한 빌드 재실행과 `git diff --check` 통과. 공식 한국어판 실물 대조·사람의 장기 대국·실기기 청음은 미실행 상태로 유지한다.


## 혼합 자원 결제 후속 보완 (2026-09-16)

- 강철·티타늄·열·호냉성 미생물을 선택한 뒤 `부족분 M€로 맞추기`로 현금만 조정한다. 서버가 제공한 금속 가치와 미생물당 2 M€를 적용하며 보유 현금 이상을 입력하지 않는다. 자원 선택과 최종 지불 확정은 플레이어가 직접 한다.
- 재료 가치가 비용보다 크면 M€를 0으로 맞추고 기존 초과 지불 경고를 유지한다. 현금이 부족하면 부족액 표시와 확정 비활성화를 유지한다. 소수·음수 등 잘못된 재료 입력으로는 자동 맞추기를 실행하지 않는다.
- 미생물도 지불 후 잔량을 표시한다. 지불 합계 변경은 스크린 리더에 알리고, 열 입력 상한은 카드 효과에서 별도로 소비할 열을 제외한다.
- Chrome 검증에 실제 식물 프로젝트의 미생물·열·M€ 혼합 지불을 추가했다. 임시 웹 자산 복사본을 사용해 병행 빌드로 인한 자산 교체를 방지한다.
- 최초 전체 검사에서 게임 목록 설명의 이전 기대 문구가 실패했다. 기업시대·프렐류드 선택을 안내하는 현재 설명에 맞춰 기대값을 수정했다.
- 타입 검사·빌드·320px Chrome 혼합 결제 검증 통과. 9 M€ 카드에 미생물 2개·열 1개·M€ 4를 지불하고 서버 차감까지 확인했다. 모바일 결제 캡처도 직접 검토했다. 기존 공통 번들 500 kB 경고는 유지된다.
- 샌드박스 내 전체 테스트 재실행은 소켓 서버의 `listen EPERM`으로 실패했으므로 로컬 포트 실행 권한을 적용해 다시 실행했다. 이 환경 실패를 규칙 테스트 통과로 취급하지 않는다.
- 최종 루트 `npm test` 통과: 공유 145개·웹 990개·서버 4,141개·공통 E2E 155개, 총 5,431개. 실패·취소·미실행 테스트 0개. `git diff --check` 통과.
