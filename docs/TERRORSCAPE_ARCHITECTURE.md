# 테러스케이프 구현 경계

[규칙](./TERRORSCAPE_GAME_RULES.md)을 따른다. 기존 Room/Session/UoW/Socket.IO 경계를 유지하는 concrete game module이다.

- `packages/shared/src/games/terrorscape`: 공개 지도 그래프·카드 설명, strict 행동 DTO와 역할별 projection. 비공개 전체 상태는 서버에만 둔다.
- `apps/server/src/games/terrorscape/domain`: deterministic 상태 전이, 카드 보존, 조우·도주·해금·발견 선택 상태. 주사위와 덱은 주입한 RandomSource로만 처리한다.
- `application`: actor/current-primary/단계/담당 캐릭터/시청자 측 revision을 방 mutation lane에서 검증한다. 후보 전체 검증 후 canonical revision을 한 번 증가시켜 commit한다. 실패는 live state 불변. requestId receipt를 사용해 재시도한다.
- `compatibility`: 저장 상태 검증, 명시적 allowlist projection. 양 팀 각각 단조 증가 revision/turnId를 사용해 숨겨진 행동 개수와 선택 단계를 상대에게 전달하지 않는다. 플랫폼 snapshot metadata는 기존처럼 wire snapshot에서 도출한다.
- `apps/web/src/features/terrorscape`: 전용 저택 보드·캐릭터/아이템 카드·지도 대상 선택·확정·협동 완료·도주/방어·음량 UI. 규칙의 최종 판정은 서버다. 모바일은 지도와 행동을 함께 사용할 수 있고 키보드로도 장소·문 선택이 가능하다.
- 자체 생성 일러스트와 Web Audio 기반 원본 공포 앰비언트·효과음을 사용한다. 첫 사용자 조작으로만 오디오 시작. 음악/효과음 별도 음량 및 정지, 화면 이탈 시 정리, 재접속 시 과거 효과 재생 금지. 숨겨진 실제 거리로 음악을 바꾸지 않는다.
- 연결 끊김은 판 유지, 명시적 나가기는 게임 취소. 같은 방 재경기/게임 교체는 기존 정책 사용. 기본적으로 in-memory이며 영구 저장·배포·새 dependency 없음.

검증 범위: domain 효과/경계/보존, 개인별 projection, 실제 Socket.IO 2–4인·중복·동시 입력·위조·재접속·종료, React 화면·모바일/키보드·오디오 수명, root typecheck/test/build 및 diff 검사. 실제 실행 결과는 완료 후 추가한다.

## 화면·사운드 구현

일러스트는 `apps/web/public/images/terrorscape/README.md`에 제작 출처를 기록했다. 저택 1장, 인물 8종, 장소 16칸, 소지품 atlas을 원본 생성한 WebP atlas로 제공한다. 추격·봉쇄·감지·전기톱 등 살인마 카드 7종과 덫/응급키트도 추가 3×3 일러스트 atlas를 사용한다. 방 연결은 SVG, 카드·인물은 HTML/CSS이므로 키보드 포커스와 목적지 select를 함께 제공한다. 전용 `tsc-` 클래스 이름으로 다른 보드게임 스타일과 격리한다.

음악은 낮은 드론/필터 노이즈/단조 음형을 실시간 합성한다. 효과음은 이동·물건·소음·봉쇄·공포·주사위·부상·차례·종료에 대응한다. 오디오 시작은 사용자 제스처로 제한하고 음악 22%, 효과음 40%로 시작한다. 별도 슬라이더와 전체 음소거를 제공하고 숨김 탭에서 suspend, 화면 종료 시 context를 닫는다. 재접속 snapshot의 과거 기록은 다시 재생하지 않는다. 큰 갑작스러운 음량을 억제하는 compressor를 사용한다.

배역 확정 전에는 초기 살인마 손패를 누구에게도 전송하지 않는다. 방장이 배역을 바꾸더라도 이전 담당자에게 카드가 노출되지 않으며, 사냥 시작 후에만 확정된 살인마에게 전달한다.

## 상태와 정보 경계 (base-v2)

- 판본 discriminator는 `terrorscape-base-v2`이다. 전체84장의 고유 ID와 종류별 수량, 선택한 살인마13장, 담당자와 단계의 일관성을 저장 상태에서 검증한다.
- 은신 실제 좌표는 살인마에게만 전달하고 상대에게는 마지막 공개 좌표를 보낸다. 감지는 `ZONE`, 두 방/범위 감지는 `PAIR`, Trail의 정확한 추적만 `LOCATION`으로 구별한다.
- 특성 초안, 생존자 선택 특성과 계획 진행은 비공개다. 확정 살인마 특성과 열쇠 수는 공개다. Separate Ways의 개인 열쇠 ID 소유권은 팀 projection에만 제공한다.
- `TRAIT_DRAFT`, 시작/종료/감지/레벨/조우 반응, `GROUP_MOVE`, `PLAN`, 재등장/공포 넘침/해금 단계는 명시적인 서버 상태다. 내부 자동 전이 단계는 settle 후에만 projection한다. 뽑기와 조우의 중단 지점을 보존한다.
- 새 인물4종과 기술10종·카메라·부적은 자체 생성 WebP atlas를 사용한다. 생성 도구와 프롬프트는 이미지 README에 기록한다. 기존 공포 배경음악과 상태 기반 효과음을 유지한다.

## 검증 기록

초기 도살자 개발판에서 Socket.IO 2–4인, 중복/동시 입력, 위조, 재접속, 지연 fanout, 모바일 경로와 오디오 수명 검증을 통과했다. 기본판 확장 후의 실행 결과는 이번 작업 완료 시 기록한다. 확장판·배포·dependency 변경은 포함하지 않는다.


### 실제 화면 검증 (2026-09-13)

별도 로컬 빌드 서버와 두 브라우저 origin에서 학살자/소피아/윌리엄/존슨 선택, 난이도/계획 설정, 양측 특성 선택, 시작 리볼버/카메라, 이동·카메라·준비 완료·발견·계획 선택·살인마 단계 진행·Stalk 은신을 확인했다. 생존자에게는 마지막 공개 위치만 표시하고 새로고침 후에도 유지한다. 390px 모바일에서 행동 탭과 Sound Decoy 사용 완료를 확인했다. document 가로 넘침 0, 두 탭의 console error/warn 0이다. 기존 오디오 생성과 수명 관리 코드는 유지한다.

### 최종 자동 검증

- 루트 `npm run typecheck`, `npm run build` 통과. 마지막 웹 변경 뒤 웹 build/typecheck도 통과했다.
- 웹 전체714개 통과. 테러스케이프 도메인54개와 실제 Socket.IO 7개를 검증했다.
- 첫 루트 `npm test` 실행은 공유131 / 웹714 / 서버2809 / 종단간155개 모두 통과했다. 마지막 재실행은 공유131 / 웹714 통과, 서버2811개 중 정령섬의 `Stage events: all configured event keys are configured once; core contains none` 1개 실패(20 !== 19)로 종료됐다. 그 실행의 테러스케이프 테스트는 모두 통과했으며, 후속 종단간 단계는 서버 실패로 실행되지 않았다. 해당 정령섬 파일들은 병행 변경 중이며 이 커밋에 포함하지 않는다.
- `git diff --check` 통과. Vite 전체 앱 JavaScript 약1.75MB의 500kB 초과 경고는 유지된다. dependency/lockfile 변경과 공개 배포는 없다.

## 저택 평면도 수정

`ManorMap.tsx`와 `manor-layout.ts`는 원본 상대 배치를 따르는 SVG 평면도와 문 좌표를 소유한다. 방별 바닥·가구·정원 및 묘역은 기존 공포 화풍을 참고해 생성한 연속 일러스트 `manor-floorplan.webp`로 표시한다. 제품 사진은 배경으로 배포하지 않는다. 일러스트는 포인터 입력을 받지 않으며 정확한 방 경계·실내 색 구역·선택 강조는 SVG 오버레이가 담당한다. 17개 문은 기존 공유 그래프와 일치하며 지도에서 마우스/키보드로 선택한다. 야외 경계는 별도 점선, 비밀 통로는 I/II 짝으로 표시한다. 경로는 문/야외 경계 좌표를 지나며, 말·소음·덫·메모는 기존 역할별 projection만 받는다. 모바일은 전체 보기와 확대/가로 스크롤을 지원한다.

화면 검증: 실제 두 역할 접속에서 메인 홀→전시실 클릭/확정과 말 이동, Enter 키를 통한 문 선택 및 선택 상태를 확인했다. 390px 모바일에서 전체 지도는 가로 넘침 없이 표시되고, 확대 시 지도만 960px로 늘어난다(문서 너비375px 유지). 전체 보기 복귀와 새로고침 복구도 확인했다. 브라우저 console error/warn 0. 문17개의 좌표가 각각 두 연결 방의 벽에 놓이는지, 야외 연결3개와 방15개가 정확히 대응하는지, 키보드 대상32개 및 역할별 말 표시를 회귀 테스트로 검증한다.

지도 수정 검증 결과: 루트 `typecheck`, `test`, `build` 통과. 전체 테스트 공유131 / 웹718 / 서버2859 / 종단간155개 통과. 마지막 아이콘·확대 안내 조정 후 웹 build/typecheck도 통과했다. `git diff --check` 통과. 기존 전체 앱 Vite 번들의 500kB 초과 경고는 유지된다.

### 평면도 일러스트 적용

단순 SVG 바닥 패턴과 가구를 연속 공포 일러스트로 교체했다. 청록색 달빛과 촛불, 낡은 가구, 정원과 묘역을 기존 `rooms.webp` 화풍에 맞췄다. 로컬 WebP 한 장(약559KiB)을 사용하며 외부 이미지 요청과 dependency 추가는 없다. 좌표 가이드와 생성/편집 프롬프트는 자산 README에 보존한다. 이미지가 입력을 가로채지 않는지 기존 지도 회귀 테스트에 추가했다.

자동 검증: 루트 typecheck 및 test 통과(공유131 / 웹719 / 서버2859 / 종단간155). 병행 작업 중인 정령섬 파일은 이 변경에 포함하지 않는다.

화면 검증: 새 일러스트가 실제 게임에 로드되는 것과 방 클릭/경로 표시, Enter 문 선택, 재접속 표시를 확인했다. 브라우저 viewport 설정이 적용되지 않아 390px iframe으로 모바일 CSS를 검증했다. 전체 지도353px, 확대960px에서 문서 clientWidth/scrollWidth 모두375px로 가로 넘침이 없었다. 두 역할 탭 console error/warn 0. 루트 build 통과, 기존 전체 앱 Vite 500kB 초과 경고 유지. `git diff --check` 통과.
