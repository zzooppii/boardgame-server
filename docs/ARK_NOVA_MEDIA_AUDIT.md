## 효과음

- 공통 35ms 제한을 소리별 중복 제한으로 변경해 선택음 직후 입주/건설/보전 소리가 누락되지 않도록 한다.
- 오디오 resume 완료 전 요청은 한 개만 대기시키며 조작음보다 결과음을 우선한다. 음소거·퇴장으로 취소된 대기음을 재생하지 않는다.
- 음량은 0–1로 제한하고, 0/음소거 시 예약 음원과 연결 노드를 정리한다. 동시 발음 수를 제한한다.
- 게임의 포인터/키 입력에서 오디오 잠금 해제를 재시도하고, 문서가 숨겨지면 소리를 중단한다.
- 실제 게임에 건설·입주·보전 미리 듣기 버튼과 음량 %를 추가한다.
- 자동 검증은 중복, 첫 resume, 음소거, 퇴장 후 재생 방지와 노드 정리를 포함한다. 데스크톱 브라우저의 모바일 크기 확인은 실제 iOS/Android 기기 청취를 대체하지 않는다.
