## CONFIRMED — 이번 구현

사용자는 2026-09-13 웹 개발과 일러스트·UI·효과음·공포 배경음악을 승인했다. 앞서 제안한 저택 1개, 도살자 1종, 생존자 3종으로 시작부터 종료까지 가능한 개발판이 범위다. 기본판 전체/확장 완성을 의미하지 않는다.

규칙 기준은 [공식 v2 룰북](https://c.tabletopia.com/games/terrorscape/rules/rules/en). 카드·지도 사실은 [제작사 공개 안내](https://terrorscape.backerkit.com/hosted_preorders/project_updates?page=5)가 연결한 [온라인 자료](https://steamcommunity.com/sharedfiles/filedetails/?id=2961401913)와 대조했다. 오래된 플레이어 보조표의 턴 시작 뽑기는 사용하지 않고 v2의 턴 종료 3장 뽑기를 따른다. 원본 그림·룰북 파일은 배포하지 않는다.

- 2–4명. 살인마 1명, 생존자 캐릭터는 Anna/William/Marco 3명. 각 생존자 측 플레이어가 적어도 한 캐릭터를 담당한다. 준비 단계에서 방장이 살인마와 담당자를 지정하고 확정한다.
- 시간 제한 없음. 생존자 팀의 행동 순서는 자유이며 기본 행동은 캐릭터당 한 번. 추가 행동/동일 장소 아이템 전달은 팀 차례에 가능하다. 수신측 용량 초과는 수신 담당자의 별도 선택으로 해결한다.
- 생존자는 이동 1–2, 공포 모두 제거, 특수 행동, 현 위치 봉쇄 제거, 무전기 수리, 지정 장소 수색 중 하나를 수행한다. 기본 행동을 모두 마친 뒤 팀원별 완료 의사를 표시하고 발견 담당자를 정한다.
- 수리는 B1에서, 살인마가 없는 경우만 가능. 라운드당 수리 1회, 기본 +1/공구상자 +2, 소음 생성. 수리 5로 구조 요청; 이후 생존자 턴 시작마다 구조 5→0. 구조 카운트는 생존자 팀 비공개다.
- 수색은 R2/B4/G4에서, 살인마가 없는 경우에 한해 1장. 발견은 팀 종료 때 지정 캐릭터에게 2장 중 최대 1장. 뽑기 소음은 버린 카드도 적용, Anna의 수색만 소음 면제(발견은 면제 아님). 새 소음은 팀 종료 때 공개하고 공포 넘침/봉쇄 제거는 즉시 공개한다.
- 생존자 시작 단계에 열쇠 5 이상 + 전원 R1이면 탈출. 비밀 지도가 있으면 전원 G5도 가능. 한 명이라도 두 번째 부상을 입으면 살인마 승리. 발견 덱이 비었고 구조 중이 아니면 발견 단계에서 살인마 승리.
- 방어 주사위 면은 0/1/1/1/1/3. 공포 0–2에 따라 주사위 4–2개. 세 번째 공포는 토큰 추가 없이 현 위치 소음을 즉시 공개한다.
- 조우: 수색으로 같은 방 생존자를 발견 → 팀이 방어자 선택 → 해당 담당자가 아이템 최대 하나 선택(리볼버+탄약 예외) → 서버 굴림 → 방어≥공격력 성공. 성공 시 살인마 덱 2장 버리고 조우 종료. 실패 시 부상 및 아직 방어하지 않은 생존자로 반복. 조우 후 그 방의 생존자 각각 선택적으로 인접 한 칸 도주, 살인마 턴 종료.
- 도살자: 기본 공격력 5, 2레벨 +1, 3레벨 난폭한 분노 해금, 4레벨 전기톱이 빠른 카드, 5레벨 조우 즉시 전원 부상 후 방어. 5레벨 이후 덱 재구성 시 추가 능력 없음.
- 도살자 덱 12장 + 잠긴 분노 1장: 추격 3, 봉쇄 3, 감지 2, 전기톱 2, 광기 1, 꼼짝 마 1. 빠른 카드 자유 사용 → 특수 카드 하나 또는 기본 이동/수색 2회 → 느린 카드 최대 하나 → 3장 뽑기. 5장 초과 새 카드 자동 버림. 덱이 빈 상태에서 뽑거나 버리려 하면 레벨 효과 먼저 적용 후 버림패를 재구성. 분노 해금 때 손이 가득 차면 새 분노를 포함한 6장 중 한 장을 선택해 버린다.
- 전기톱(비용 2): 거리 1 공포 → 0–1 이동 → 현 위치 전원 직접 부상. 광기(비용 2): 현 위치 문 하나 봉쇄 → 이번 턴 공격력 +2. 꼼짝 마(비용 4): 현 위치 모든 문 봉쇄. 분노(비용 1): 1–2 이동 → 수색. 발견 실패하고 이 이동에서 봉쇄를 제거했다면 이동·수색 반복. 봉쇄 7개 한도에서 재배치 대상을 직접 선택한다.
- Anna: 감지 면제, 수색 뽑기 소음 면제. William: 무기 미사용 방어 +1, 기본 행동 대체 3칸 달리기 후 목적지 소음. Marco: 전용 응급키트로 시작, 기본 행동으로 버림패의 아드레날린/진정제 회수. 응급키트는 Marco만 사용하며 같은 방 부상자 치료와 공포 제거.

## 온라인 정보 경계

생존자 위치·손패·열쇠·수리·구조·덫·발견 후보·개별 행동 상태는 생존자 팀만 받는다. 살인마 손패·덱 순서·장수는 살인마만 받는다. 공개되는 지도·부상·공포·감지 결과·사용 카드·조우 결과는 양쪽에 전달한다. 실제 위치와 추측 메모를 구별한다. 팀 핑은 생존자 팀만, 살인마 추측 메모는 개인 브라우저에 저장한다.

같은 방이라도 시청자 측 revision과 turnId를 사용한다. 서버 저장 revision은 별도로 증가하며 명령은 현재 actor 측 revision, 단계, 담당 권한을 검증한다. 숨겨진 행동으로 상대 측 revision을 증가시키지 않는다. 서버가 허용한 사실만 기록·애니메이션·음향에 사용한다.

## TO_BE_CONFIRMED / 후속 범위

나머지 기본판 생존자/살인마, 은신 능력, 확장·변형, 관전, 전체 리플레이, 서버 재시작 후 영구 복원은 미구현이다. 이 개발판은 도살자에게 없는 은신 기능을 임의로 추가하지 않는다. 캐릭터/아이템 한글명과 설명은 자체 번역이며 정식 한국어판 문구 일치를 주장하지 않는다. 공개 배포는 이번 작업에 포함하지 않는다.

## 온라인 조작 세부사항

- 발견 후 소지품 4장이 되면 담당자가 1장을 버릴 때까지 살인마 차례를 시작하지 않는다. 발견 전에는 세 캐릭터 모두 기본 행동 및 준비 완료가 필요하다.
- 방어자는 각 캐릭터 담당자가 자기 캐릭터를 선택한다. 먼저 수락된 선택 하나만 확정한다. 도주는 담당자별로 이동 또는 머무르기를 확정한다.
- 목적지 자동 경로 외에 직접 경로 선택으로 중간 장소를 지정할 수 있다. 이동 횟수·인접성·봉쇄 판정은 경로 전체를 서버에서 검증한다.
- 공개되는 공포·부상 변화와 봉쇄 제거는 상대가 관찰할 수 있다. 위치·소지품·수리·발견 후보·팀 핑은 생존자 팀 전용이다. 접속 상태 변화는 기존 플랫폼의 공개 정보다.
