# 테러스케이프 — 영문 v2 기본판

## CONFIRMED — 이번 구현

사용자는 기본판의 빠진 콘텐츠와 규칙 보충을 요청했고, 정식 한국어판 자료 대신 영문판 기준 개발을 승인했다. 저택 지도, 살인마 3종, 생존자 5종, 기본판 아이템·기술·특성·생존 계획·각자 탈출을 범위로 한다. 한국어 설명은 자체 번역이다.

규칙 기준은 [공식 v2 룰북](https://c.tabletopia.com/games/terrorscape/rules/rules/en). 카드·지도 사실은 [제작사 공개 안내](https://terrorscape.backerkit.com/hosted_preorders/project_updates?page=5)가 연결한 [온라인 자료](https://steamcommunity.com/sharedfiles/filedetails/?id=2961401913)와 대조했다. 오래된 플레이어 보조표의 턴 시작 뽑기는 사용하지 않고 v2의 턴 종료 3장 뽑기를 따른다. 원본 그림·룰북 파일은 배포하지 않는다.

- 2–4명. 살인마 1명, 생존자 캐릭터는 Anna/William/Marco/Sophia/Johnson 중 3명. 각 생존자 측 플레이어가 적어도 한 캐릭터를 담당한다. 준비 단계에서 방장이 살인마와 담당자를 지정하고 확정한다.
- 시간 제한 없음. 생존자 팀의 행동 순서는 자유이며 기본 행동은 캐릭터당 한 번. 추가 행동/동일 장소 아이템 전달은 팀 차례에 가능하다. 수신측 용량 초과는 수신 담당자의 별도 선택으로 해결한다.
- 생존자는 이동 1–2, 공포 모두 제거, 특수 행동, 현 위치 봉쇄 제거, 무전기 수리, 지정 장소 수색 중 하나를 수행한다. 기본 행동을 모두 마친 뒤 팀원별 완료 의사를 표시하고 발견 담당자를 정한다.
- 수리는 B1에서, 살인마가 없는 경우만 가능. 라운드당 수리 1회, 기본 +1/공구상자 +2, 소음 생성. 수리 5로 구조 요청; 이후 생존자 턴 시작마다 구조 5→0. 구조 카운트는 생존자 팀 비공개다.
- 수색은 R2/B4/G4에서, 살인마가 없는 경우에 한해 1장. 발견은 팀 종료 때 지정 캐릭터에게 2장 중 최대 1장. 뽑기 소음은 버린 카드도 적용, Anna의 수색만 소음 면제(발견은 면제 아님). 새 소음은 팀 종료 때 공개하고 공포 넘침/봉쇄 제거는 즉시 공개한다.
- 생존자 시작 단계에 열쇠 5 이상 + 전원 R1이면 탈출. 비밀 지도가 있으면 전원 G5도 가능. 한 명이라도 두 번째 부상을 입으면 살인마 승리. 발견 덱이 비었고 구조 중이 아니면 발견 단계에서 살인마 승리.
- 방어 주사위 면은 0/1/1/1/1/3. 공포 0–2에 따라 주사위 4–2개. 세 번째 공포는 토큰 추가 없이 현 위치 소음을 즉시 공개한다.
- 조우: 수색으로 같은 방 생존자를 발견 → 팀이 방어자 선택 → 해당 담당자가 아이템 최대 하나 선택(리볼버+탄약 예외) → 서버 굴림 → 방어≥공격력 성공. 성공 시 살인마 덱 2장 버리고 조우 종료. 실패 시 부상 및 아직 방어하지 않은 생존자로 반복. 조우 후 그 방의 생존자 각각 선택적으로 인접 한 칸 도주, 살인마 턴 종료.
- 도살자: 기본 공격력 5, 2레벨 +1, 3레벨 난폭한 분노 해금, 4레벨 전기톱이 빠른 카드, 5레벨 조우 즉시 전원 부상 후 방어. 5레벨 이후 덱 재구성 시 추가 능력 없음.
- 도살자 덱 12장 + 잠긴 분노 1장: 추격 3, 봉쇄 3, 감지 2, 전기톱 2, 광기 1, 꼼짝 마 1. 빠른 카드 자유 사용 → 특수 카드 하나 또는 기본 이동/수색 2회 → 느린 카드 최대 하나 → 3장 뽑기. 5장 초과 새 카드 자동 버림. 덱이 빈 상태에서 뽑거나 버리려 하면 레벨 효과 먼저 적용 후 버림패를 재구성. 분노 해금 때 손이 가득 차면 새 분노를 포함한 6장 중 한 장을 선택해 버린다.
- 전기톱(비용 2): 거리 1 공포 → 0–1 이동 → 현 위치 전원 직접 부상. 광기(비용 2): 현 위치 문 하나 봉쇄 → 이번 턴 공격력 +2. 꼼짝 마(비용 4): 현 위치 모든 문 봉쇄. 분노(비용 1): 1–2 이동 → 수색. 발견 실패하고 이 이동에서 봉쇄를 제거했다면 이동·수색 반복. 봉쇄 7개 한도에서 재배치 대상을 직접 선택한다.
- Anna: 감지 면제, 수색 뽑기 소음 면제. William: 무기 미사용 방어 +1, 기본 행동 대체 3칸 달리기 후 목적지 소음. Marco: 전용 응급키트로 시작, 기본 행동으로 버림패의 아드레날린/진정제 회수. 응급키트는 Marco만 사용하며 같은 방 부상자 치료와 공포 제거.
- 수색 덱 10장 + 바닥 열쇠 1장: 열쇠4, 공구2, 위스키/손도끼/약초/석회가루 각1. 발견 덱32장: 탄약/약초/아드레날린/손도끼/진정제/위스키 각3; 공구/리볼버/열쇠 각2; 폭죽/부적/단검/지도/석회가루/손전등/장검/덫 각1. 전체 아이템은 덱43장 + Marco 키트 + Sophia 카메라 =45장이다. 선택하지 않은 인물의 전용 아이템은 비활성 보관한다. 살인마별 덱13장, 전체39장을 보존한다.

## 온라인 정보 경계

생존자 위치·손패·수리·구조·덫·발견 후보·개별 행동 상태는 생존자 팀만 받는다. 살인마 손패·덱 순서·장수는 살인마만 받는다. 공개되는 지도·부상·공포·감지 결과·사용 카드·조우 결과는 양쪽에 전달한다. 실제 위치와 추측 메모를 구별한다. 팀 핑은 생존자 팀만, 살인마 추측 메모는 개인 브라우저에 저장한다.

같은 방이라도 시청자 측 revision과 turnId를 사용한다. 서버 저장 revision은 별도로 증가하며 명령은 현재 actor 측 revision, 단계, 담당 권한을 검증한다. 숨겨진 행동으로 상대 측 revision을 증가시키지 않는다. 서버가 허용한 사실만 기록·애니메이션·음향에 사용한다.

## TO_BE_CONFIRMED / 후속 범위

확장판, 관전, 전체 리플레이, 서버 재시작 후 영구 복원은 범위 밖이다. 한국어판 정식 명칭과 인쇄판별 문구 일치는 미대조다. 영문 v2와 공개 개정 안내를 우선하며 오래된 보조표와 카드가 충돌하면 카드/FAQ를 따른다. 공개 배포는 포함하지 않는다.

## 온라인 조작 세부사항

- 발견 후 소지 한도를 넘으면(존슨은 무제한) 담당자가 초과 카드를 버릴 때까지 살인마 차례를 시작하지 않는다. 발견 전에는 세 캐릭터 모두 기본 행동 및 준비 완료가 필요하다.
- 방어자는 각 캐릭터 담당자가 자기 캐릭터를 선택한다. 먼저 수락된 선택 하나만 확정한다. 도주는 담당자별로 이동 또는 머무르기를 확정한다.
- 목적지 자동 경로 외에 직접 경로 선택으로 중간 장소를 지정할 수 있다. 이동 횟수·인접성·봉쇄 판정은 경로 전체를 서버에서 검증한다.
- 공개되는 공포·부상 변화와 봉쇄 제거는 상대가 관찰할 수 있다. 위치·소지품·수리·발견 후보·팀 핑은 생존자 팀 전용이다. 접속 상태 변화는 기존 플랫폼의 공개 정보다.

### CONFIRMED — 공통 규칙 정정

- 감지는 선택한 구역 안의 생존자 이름만 알려준다. 정확한 방 좌표를 상태·DTO·지도에 포함하지 않는다. 안나의 감지 면제는 유지한다.
- 공구상자는 뽑을 때 소음이 발생하는 카드다. 안나의 수색 면제는 유지되지만 발견에는 적용하지 않는다.
- 살인마는 남은 기본 행동을 포기하고 느린 카드 단계로 넘어갈 수 있다.

근거: 기존 공식 공개 카드와 [한국어 잔룰 정리 및 디자이너 답변 링크](https://boardlife.co.kr/bbs_detail.php?bbs_num=2299&tb=board_knowhow), [기본 행동 포기에 대한 디자이너 답변](https://boardgamegeek.com/thread/3261921/article/43946216#43946216). 구역 감지는 당시의 결과이며 이후 이동을 실시간 추적하지 않는다.

## CONFIRMED — 영문 기본판 기준 전환 (2026-09-13)

사용자가 영문판 기준 개발을 승인했다. 영문 v2 룰북/FAQ를 우선하고, [제작사의 확정 개정 안내](https://terrorscape.backerkit.com/hosted_preorders/project_updates?page=5) 및 그 안내에서 제공하는 카드 자료를 대조한다. 화면은 한국어로 설명하되 영문 카드명도 병기한다.

- 기본판 살인마 3종, 생존자 5종 중 정확히 3명을 선택한다. 담당자 배정과 인물 선택은 준비 단계 방장 권한이다.
- 망령 공격력 2(구판 보드 3은 사용하지 않음). 조우 시 대상 전원 공포. Lv2 Whizz 후 손패 2장으로 추가 수색, Lv3 공포 넘침마다 선택적으로 손패 3장을 버려 해당 생존자 부상, Lv4 Life Drain 해금, Lv5 조우 직후 전원 부상.
- 학살자 공격력 4. Lv2 재등장 조우 공격력 +3, Lv3 Death Blossom 해금, Lv4 공격력 +2와 지도 문 4개 봉쇄, Lv5 조우 직후 전원 부상. 구판 Swift Slaughter 대신 Death Blossom 카드와 v2 FAQ를 따른다. Stalk는 매 공격 전에 한 장으로 +1 또는 느린 카드로 0–2칸 은신.
- 은신은 봉쇄를 통과하지만 제거하지 않는다. 상대는 마지막 공개 위치만 알며 실제 은신 위치에서는 수색·수리가 가능하다. 다음 살인마 차례 시작에 위치 공개 → 재등장 효과 → 무료 수색. 조우하면 이후 일반 행동은 생략한다.
- 소피아는 카메라로 시작하며 비밀 통로를 기본 행동으로 이용한다. 손전등을 소유하면 그 능력은 추가 행동이다. 카메라는 소피아 전용 일회용 추가 행동으로 현 위치 소음을 발생시킨다.
- 존슨은 소지품 제한이 없고 공구상자 수리량 +1. 기본 수리량은 여전히 1이다.
- Ancient Amulet는 조우 공격 외 피해 한 번을 막고 버린다. Death Blossom의 즉사와 Lv5 조우 시작 부상은 막지 못한다. 구판의 턴 시작 공포 감소는 적용하지 않는다.
- 공개 열쇠 수는 양측에게 전달한다. 손패·덱·수리·구조 카운트와 은신 실제 경로는 기존 비공개 경계를 지킨다.

### CONFIRMED — 기본판 생존 계획 변형

영문 v2 p29의 두 장 뽑기/발견 종료 시 한 단계 진행/다른 계획으로 전환 시 진행 소실/한 계획 완료 후 다른 계획 폐기를 적용한다. 공개 카드 16종의 조건과 효과는 공유 `plans.ts`에 정리한다. 저택의 책/도구/주술/수리 기호는 각각 R5/G3/G2/B1이다. 계획·진행·설치 위치는 생존자 팀 비공개이며, 카드가 지정한 소음과 승리만 공개한다. 은신 중에는 살인마 위치 조건을 충족할 수 없다.

### CONFIRMED — Separate Ways (4인)

영문 v2 p28을 따른다. 개인 열쇠 3개로 개별 탈출, 최초 발견 담당자 무작위 선정과 생존자 순환, 실제 수리 진행량만큼 수색 카드 보상, 사망해도 계속 진행 및 살인마 1레벨 증가, 같은 장소 시신의 아이템·열쇠 회수를 적용한다. 탈출한 생존자는 승자로 남고 사망자는 제외한다. 살인마는 2명 이상 제거 시 승리하며 3명 전원 제거를 별도 표시한다. 구조 시 살아 있는 생존자만 승리한다. 공통 규칙의 발견 덱 소진 패배는 여전히 적용한다.

### CONFIRMED — 특성 40종과 난이도

영문 v2 p27 및 공개 특성 카드 40종을 따른다. 쉬움/보통/어려움/악몽에서 생존자는 각각 2장 중 1장, 살인마는 각각 0/2/4/6장 중 0/1/2/3장을 선택한다. 생존자 특성은 팀 비공개, 선택을 마친 살인마 특성은 공개한다. 일회용 카드는 사용 기록으로 재사용을 금지한다. 시작·종료·감지 직후·레벨업·조우 전 반응을 명시적인 선택 단계로 처리한다.

## 처리 순서와 온라인 선택

- 비용 카드는 먼저, 사용 기술 카드는 마지막에 버린다. 장검으로 인한 뽑기/레벨업/해금 선택을 해결한 뒤 방어 주사위를 굴린다. 덫은 실제 굴림 직후 공개·소모한다. 화염병으로 방어 보너스를 받으면 Martial Arts의 무도구 보너스를 받지 않는다.
- 보상 수색 카드는 모두 받고 소지 한도 초과분을 별도 선택한다. 일반 수색/발견은 최대 한 장 보관이다. 사망·탈출한 캐릭터는 보상 대상이나 치료 대상으로 선택할 수 없다.
- 캐릭터·특성·계획 및 모든 반응은 서버에서 판정한다. 조우 중 레벨업이 발생해도 해금/봉쇄/특성 선택 후 중단된 조우를 이어간다.
- UI는 일반 행동, 카드 경로, 감지 구역·두 방, 비용, 대상, 봉쇄 재배치와 반응 포기를 제공한다. 사용한 일회용 특성은 표시하고 재사용은 서버에서 거부한다.

- Tunnels Investigation 완료 시 손전등도 연결된 네 입구 사이를 이동할 수 있다. 소피아는 손전등을 보유한 통로 이동을 추가 행동으로 처리한다. 계획 완료 시 선택하지 않은 계획은 폐기한다.
