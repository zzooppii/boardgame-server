# 스피크이지 개발 현황

## 지금 플레이할 수 있는 범위

컴퓨터 상대 11턴 **별도 연습 규칙** 대국은 시작부터 최종 정산까지 가능하다. 건설·생산·운송·판매·보호·트럭 이동, 경찰과 지역 수입, 행동 미리보기·효과음·결과 기록, 길잡이·개인 사업 현황·다음 정산 예고를 제공한다. 공식 솔로 모드나 원작 기본판의 완성은 아니다.

## 원작 기본판까지 남은 순서

1. **구성물 데이터 확인**: 운영 카드 48장, 마피아 타일 20개, 도시 타일 54개, 도우미·목표·부두·인원별 지도/행동 자리의 개별 값과 효과를 원본 자료에 대조한다. 공급 소진 예외도 확인한다. [미확정 목록](./SPEAKEASY_GAME_RULES.md)의 값은 예제로 채우지 않는다. 원작 자동 설정의 선행 조건이다.
2. **원작 한 판의 연결**: 이미 있는 순수 규칙 모듈을 검증된 초기 설정·카포 배치·장소별 복합 효과·카드/도시 타일 선택·목표·마피아 방어·막 전환·최종 점수로 연결한다. 개별 모듈 테스트가 전체 대국 완성을 의미하지 않는다.
3. **사람 간 온라인 대국**: 방/참가/인증과 서버 명령 서비스를 연결하고 원작 보드·개인판·손패·추가 선택 화면을 구현한다. 서버가 실행 중인 동안의 연결 복구, 중복 입력, 참가자 이탈을 처리한다.
4. **실제 완주 검증과 마감**: 2/3/4인 다중 브라우저 완주, 카드별 회귀, 모바일·키보드·음향을 확인한다. 원작 구성물 및 타인의 비공개 정보 노출 여부를 함께 검사한다.

## 한 판 연결 진행

- 일반 장소 행동 큐: 등록된 자리에서 줄 순서·같은 줄 선택 순서·건너뛰기·완료와 필수 뽑기를 연결했다. 장부 획득·고용·보호·운영 카드·최대 2회 건설, 생산·트럭 운송·선박 주류 구매/공격·상자 교체/빈 항구 이동·판매와 수준 1 증가/즉시 악명 보상, 조직원의 VIP/부두 배치·기존 조직원 재배치·신규 배치 보상 처리를 연결했다. 시험용 구성을 통해 일반 장소로 2인 22차례 서비스 완주를 검사한다. 원작 자리 전체 구성, 미지원 도우미/추가 수준 증가 및 개별 악명 보상 데이터와 온라인 조작 화면은 남아 있다.

- 준비 라운드 연결: 2인 부두 선배치와 2/3/4인 역순 첫 건물·도시 타일 획득·운영 카드 상단 보너스를 처리하고, 전원 완료 후 일반 명령 서비스의 첫 차례로 넘긴다. 원본 6쪽에서 준비 순서와 카드 행동/턴 종료 뽑기 제외를 확인했다. 실제 초기 구성물 생성·개별 보너스 catalog·온라인 준비 UI는 남아 있다.

- 명령 서비스가 라운드 정산 → 마피아 공개/방어 → 경찰/지역 수익 → 다음 막 → 최종 결과까지 자동 진행한다. 서버에 주입한 합성 구성물과 레스토랑 명령으로 2인 22차례의 서비스 완주를 검증한다. 실제 초기 설정·일반 장소/구성물 효과·실시간 화면 연결은 아직 남아 있으며, 이 테스트를 원작 대국 출시 완료로 간주하지 않는다.

## 원작 자료 대조 진행

- 고정 목표 화면: 서버 응답에 본인 진행 수치·수익·장부 칸·배치 불가 사유를 추가하고 지도·개인판 미리보기에서 펼쳐 볼 수 있도록 구현했다. 실제 목표 배치 조작과 실시간 대국 연결은 남아 있다.

- 보드 고정 목표 9개: 부두 상자 1/2/3, 시청 보호 구역 3/5/7, 악명 10/15/22의 공식 조건·지급액을 확인하고 PLACE_BOOK 서버 명령에 연결했다. 타일 목표의 개별 보너스와 대국 화면 연결은 남아 있다.

- 목표 타일 준비 모듈: 지역 3개와 센트럴파크 A/A/B/B/C 배치, 번호 중복 건너뛰기, 미사용 타일 반환을 구현했다. 실제 목표 조건·보너스 catalog와 장부 상태 연결은 남아 있다.

- 원작 보드 준비 모듈: 2인 폐쇄 2/2/1 구역, 인원별 건물 칸, 초기 마피아 4/6개, 초기 경찰 4개와 1–3막 구역 일정을 구현했다. 기존 경제·Luciano 모듈과 2/3/4인 연결을 검증한다. 전체 자동 설정에는 나머지 구성물 catalog와 플레이어 준비 화면 연결이 필요하다.

- 2026-09-17: Rules v19c 및 Player Aid v12를 대조했다. 2인 폐쇄 구역의 경찰 배치를 잘못 거절하던 서버 검증을 수정하고, 경찰 진입부터 금고 정산까지 회귀 검증을 추가했다.
- 미드타운·업타운의 3–4인 지급표는 확인했다. 다운타운 및 2인 보드 대조가 남아 공식 전체 배당표 연결은 보류했다. 세부 값과 출처는 [규칙 문서](./SPEAKEASY_GAME_RULES.md)에 기록했다.
- 원작 초기 설정·구성물 catalog와 온라인 대국은 여전히 위 순서대로 남아 있다.

## 연습 대국에서 추가로 다듬을 수 있는 부분

- 통신 실패·느린 응답·세션 만료를 실제 브라우저에서 반복 검증하고 안내를 보완한다.
- 실제 사용자 플레이로 컴퓨터 상대의 반복 행동과 난이도를 평가한다. 난이도 변경은 아직 구현하지 않았다.
- 효과음의 실제 기기 청취와 터치 조작을 확인한다. 현재 브라우저 동작 검증이 청취 평가를 대신하지 않는다.

연습 UI를 계속 다듬는 것만으로 원작 기본판이 완성되지는 않는다. 원작 구현의 우선 병목은 구성물 데이터 확인이며, 이후 전체 흐름과 온라인 연결 순으로 진행한다.

## 제외된 작업

사용자 요청에 따라 서버 재시작 후 복구·파일/DB 영구 저장은 개발하지 않는다. 확장판과 공식 솔로 모드는 현재 기본판 범위에 포함하지 않는다.
