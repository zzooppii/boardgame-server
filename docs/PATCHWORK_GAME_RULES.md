## 기준 자료와 구성

- [Lookout 공식 기본 규칙서](https://www.lookout-spiele.de/upload/en_patchworkanniversary.html_PW10_Rules_EN_web.pdf): 기본 2인 게임, 구매 순서, 연속 차례, 수입, 가죽 조각, 종료·동률.
- [공식 판본 FAQ](https://www.lookout-spiele.de/en/games/patchwork.html): 구판 첫 가죽 조각의 뒤쪽 이동. 수정된 기본판을 사용한다.
- 조각 33개의 칸 형태·가격·시간·수입이라는 구성품 사실은 [PatchworkSim의 구성품 데이터](https://github.com/danzel/PatchworkSim/blob/master/PatchworkSim/PieceDefinition.cs)를 전사하고 사용자 첨부 참고 화면에서 읽히는 구성과 대조했다. 이 구현의 알고리즘과 그래픽은 가져오지 않았다. 해당 구현의 **구판 가죽 위치는 채택하지 않았다**. 별도로 조사한 `ccoppetti/patchwork-game`은 임시 조각 데이터가 포함되어 근거에서 제외했다.
- 카탈로그: `packages/shared/src/games/patchwork/catalog.ts`. 1번은 1×2 시작 조각, 0번은 가죽 조각 종류다. 종류 번호와 실제 인스턴스 `tileId`는 별개다.
- 9×9 보드 2개, 일반 조각 33개, 가죽 조각 5개, 단추 5개씩. 시간 위치 0~53. 수입은 5/11/17/23/29/35/41/47/53, 수정판 가죽은 26/32/38/44/50이다.

## 진행

1. 서버가 조각을 섞고 1×2 조각 바로 다음에 중립 말을 둔다. 선공은 서버 RandomSource로 무작위 선정한다.
2. 시간판에서 뒤의 플레이어가 행동한다. 같은 칸이면 가장 최근 도착한 위쪽 말의 플레이어가 다시 행동한다.
3. BUY: 중립 말 다음 최대 3개 중 하나를 선택, 비용 지불, 회전/반사한 조각을 빈칸에 배치, 시간 이동. 구매·배치는 한 번의 서버 commit이다. 놓았던 조각은 이동하지 않는다.
4. ADVANCE: 상대 위치+1까지 이동하되 53에서 정지. **실제 이동 거리**만큼 단추를 받는다.
5. 수입 지점에 도달하거나 통과하면 현재 퀼트 수입을 받는다. 이번에 산 조각의 수입도 포함한다. 한 이동에 지나는 모든 지점을 처리한다.
6. 먼저 도달한 가죽 조각들을 확보하여 순서대로 즉시 배치한다. 모든 가죽 배치 전 다음 차례로 넘기지 않는다. 가죽은 단추·시간 비용이나 수입이 없다. 보드가 꽉 찼다면 남은 확보 가죽은 제거한다(온라인 교착 방지 정책). 제거된 실제 타일도 서버에 보존한다.
7. 처음 7×7 영역을 모두 채운 플레이어는 +7 보너스. 일반 조각과 가죽 배치 직후 모두 확인한다.
8. 두 말이 53에 도착하고 가죽 배치를 마치면 종료. 점수 = 단추 + 보너스 − 빈칸×2. 동점이면 53에 먼저 도착한 플레이어가 승리한다.

## 온라인 운영·공개 범위

- 2인 시작. 방의 공통 대기실 참가/준비 흐름을 재사용한다. 다른 게임에서 사람이 더 많은 방으로 전환은 가능하지만 정확히 2명이 아니면 시작을 거절한다.
- 2026-09-16 사용자 요청 및 시간 초과 처리 선택으로 확정: 대기실 방장이 차례당 30초 또는 60초를 선택한다(기본 60초). 게임 중 변경할 수 없다. 게임 내 시간 비용과 벽시계 제한은 별개다.
- 서버 마감 시각에 도달하면 행동을 거절하고 자동 전진한다. 미확정 구매는 로컬 미리보기이므로 취소한다. 가죽 배치 중에는 전진하지 않고 확보한 가죽을 위쪽 왼쪽 빈칸부터 모두 자동 배치한다. 자동 전진으로 얻은 가죽도 같은 처리에서 배치한다.
- 가죽 배치는 같은 차례의 남은 시간을 사용한다. 모든 배치가 끝나면 같은 플레이어가 연속 행동하더라도 새 제한 시간을 부여한다. 오프라인에서도 제한 시간은 흐르며 재접속으로 연장되지 않는다. 재시작 시 방장의 설정을 유지한다. 기존 무제한 저장 게임은 다음 행동을 완료하면 제한 시간을 적용한다.
- 모든 확정 조각, 시장 순서, 단추, 수입, 보드, 시간판, 가죽 배치 대기와 점수를 두 참가자에게 공개한다. 로컬 미확정 배치는 전송하지 않는다.
- 연결 끊김은 상태를 보존하며 복귀 시 현재 서버 상태에서 이어간다. 명시적 나가기는 승자 없는 CANCELLED. 기존 방 retention을 따른다. 종료 후 방장이 60초 이상 오프라인이면 연결된 다른 참가자가 방장을 승계한다.
- 같은 방 재시작/다른 게임 선택을 지원한다. 재시작은 새 게임 ID, 새 타일 ID, 새 셔플이다.
- 서버 재시작을 넘는 영구 저장, AI·솔로·확장·랭킹·공개 배포는 이번 작업 범위에 포함하지 않는다.
