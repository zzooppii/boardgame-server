# 7 Wonders Duel 아키텍처

- `packages/shared/src/games/seven-wonders-duel`: 공개 구성물, 직렬화 DTO, 설정, SELECT 명령.
- `apps/server/src/games/seven-wonders-duel/domain`: 전체 비공개 상태, 시대 배치, 비용, 효과 큐, 승리 판정. 난수·시간·ID를 주입한다.
- application은 방별 직렬화, 인증, 멱등성, room/game revision 및 transition ID를 검사하고 검증된 candidate만 commit한다.
- compatibility projection은 시점별 공개 정보와 viewer 자신의 선택만 내보낸다. 신화 덱, 제거된 비공개 카드, 상대 음모, 숨겨진 법령은 원시 상태로 전송하지 않는다.
- 추가 선택은 서버 task queue에 저장된다. 본행동, 효과의 대상 선택, 카드 공개, 턴 인계를 구분한다. 재접속은 동일 projection과 선택 목록을 복원한다.
- 웹은 테이블 배치, 카드 확대, 선택 확인, 연계 참고표, 이벤트 기반 음향을 담당한다. 프론트가 판정을 수행하지 않는다. 비공개 정보의 사운드나 애니메이션도 공개 이벤트만 사용한다.
- 음향은 사용자 조작 이후 Web Audio로 합성하고 음소거를 제공한다. reduced-motion, 키보드 및 터치 조작을 지원한다.

기존 room/session 수명주기와 server-authoritative 경계는 유지한다. 전용 테이블 및 자산은 게임 선택 후 로드한다.

## 복합 규칙 및 전체 플레이 품질 검수 (2026-09-15)

### 규칙과 선택 경계

- 하데스 → 정치가 고용 → 방패 법령 → 군사 토큰의 영향력 효과 → 남은 정치가 행동 순서를 회귀 테스트로 고정했다. 남은 정치가 행동이 군사 토큰 효과보다 앞서던 오류를 수정했다.
- 신들의 극장 → 이시스 → 쿠리아 율리아 → 미준비 음모 → 신화 덱 순서 복원 및 추가 턴을 검증한다.
- 관문 → 엔키 → 법률/이슈타르 과학 쌍, 넵투누스 군사 토큰의 정치 승리, 협박과 아스타르테 보호 코인, 강요의 양쪽 동시 과학 승리, 아누비스 → 이시스 → 영묘 재건 및 버린 건물 부활을 검증한다.
- 비공개 카드 선택은 행과 행 내 위치를 함께 표시한다. 확대 화면은 실제 선택한 대상에 해당하는 행동만 보여주며, 단순히 `definitionId === null`인 다른 대상은 포함하지 않는다.
- 판테온 활성화 선택의 공개 `sourceId`는 `pantheon-<자리>`로 구별한다. 의회 위치의 숫자 ID와 화면상 연결이 겹치지 않도록 한 변경이며 서버 SELECT/revision 검증은 동일하다.

### 화면 개선

- 건설·버리기 선택과 공개 기록에 카드 이름을 표시한다.
- 모바일에서 현재 선택 안내를 고정하고 효과 선택 목록으로 이동하는 링크를 제공한다.
- 보유 건물·토큰의 작은 글씨와 흰 의원 카드의 대비를 개선하고 신화 이름을 한국어로 표시한다.
- 군사 우세의 주체와 승리 사유를 한국어로 표시한다. 종료 후 비어 있는 카드 배치의 높이를 줄여 양쪽 도시를 이어서 볼 수 있게 한다.
- 로딩 최적화·정식 배포는 이번 범위에 포함하지 않는다.
