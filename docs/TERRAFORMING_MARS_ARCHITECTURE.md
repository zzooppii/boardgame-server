# 테라포밍 마스 아키텍처

기존 Room/Session/Socket.IO/직렬 실행/멱등성 경계를 이용하는 `TERRAFORMING_MARS` 전용 구현이다. 게임 규칙은 `games/mars/domain`, 입출력·원자적 저장은 `application`, 비공개 상태를 플레이어별로 분리하는 코드는 `compatibility`에 둔다. 공유에는 공개 카드 정보와 직렬화 가능한 계약만 둔다.

서버가 선택 가능한 행동과 배치 칸, 비용을 계산하고 실행 시 다시 검증한다. 각 명령은 복제한 상태를 완전히 검증한 후 한 번만 저장한다. 효과 도중 추가 선택이 필요한 경우 서버 상태에 대기 선택을 저장한다. 클라이언트는 비공개 덱·다른 손패·서버 효과 큐를 받지 않는다. 재접속·오래된 revision·중복 요청은 기존 플랫폼과 동일하게 처리한다.

UI: 화성 지형을 중앙에 두고 상단 전역 지표와 자원, 하단 손패, 오른쪽 맥락별 행동 패널을 배치한다. 지도와 낸 카드를 전환하고 참가자별 공개 정보·업적·기업상을 확인한다. 클릭·터치·키보드 선택과 별도 확정으로 조작하며, 배치 후보와 예상 결과를 함께 표시한다.

일러스트는 imagegen으로 새로 생성한 지형 및 12장면 카드 atlas를 프로젝트에 저장해 사용한다. 아이콘과 타일은 읽기 쉬운 SVG/CSS로 표시한다. 효과음은 사용자의 첫 입력 뒤 Web Audio로 합성하며 음량·음소거를 제공한다. 서버가 확정한 연속 revision만 재생하여 재접속 시 과거 효과음을 반복하지 않는다. 모션 감소 설정에서는 이동 애니메이션을 줄인다.

출시 범위는 [TERRAFORMING_MARS_GAME_RULES.md](./TERRAFORMING_MARS_GAME_RULES.md)를 따른다. 영구 저장·확장은 구현 완료로 표시하지 않는다.

## 검증 (2026-09-16)

- 루트 `npm run typecheck`, `npm test`, `npm run build` 실행. 전체 테스트 5,072개 통과(공유 133 / 웹 908 / 서버 3,876 / E2E 155).
- 추가 경계 보완 후 마스 도메인 테스트 17개 재검증: 137종 개별 카드 실행, 2–5인 대국 완주, 비용·필수 열 예약, 배치·연쇄 전역 보너스, 생산·최종 녹지·점수, 카드 보존, 특허 여러 장 매각, 헬리온 연구, 홍수 순서, 초식동물 소유자 조건.
- Socket.IO 통합: 비공개 손패, 다른 참가자 명령 거절, 오래된 revision 거절, 같은 요청 재전송 1회 처리, 재접속 중 지불 선택 복원.
- 실제 Chrome 두 독립 세션: 1440×1000 및 390×844. 방 생성·참가·기업 선택·카드 지불 취소·해양 지불·키보드 배치 확정·새로고침 복구를 조작했다. 모바일 확대 후 문서 가로 넘침 없음, 브라우저 페이지 오류 없음.
- 효과음은 실제 Web Audio oscillator 생성, 음소거 시 생성 중단, 음량 설정 저장을 브라우저에서 검증했다.
- 마스 화면·CSS는 별도 청크로 지연 로딩한다. 기존 공통 앱 번들은 500kB 경고 기준을 초과하므로 전체 앱 번들 최적화는 별도 과제로 남는다.
