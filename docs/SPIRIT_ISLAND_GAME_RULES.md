# 정령섬 — 기본판 콘텐츠

2026-09-13 기본판과 플레이 완성도에 이어 사용자가 〈가지와 발톱〉 개발을 승인했다. 저장·서비스 운영·관전·AI·다른 확장팩은 제외한다. 기존 게임의 미확정 규칙은 변경하지 않는다.

## CONFIRMED — 게임 구성

- 1–4인 협동, 기본판 정령 8종. 강·번개·대지·그림자·녹음·천둥·바다·악몽. 중복 선택 없음. 기본판 고유 능력 카드 32장, 보조 36장, 주요 22장.
- 기본판 A–D 균형 보드를 게임 생성 시 서버의 RandomSource로 섞어 인원수만큼 중복 없이 선택한다. 플레이어의 board 필드 순서로 배치하며 보드 내부 지형·시작 기물은 고정이다. 연결은 기존 디지털 배치의 슬롯별 접합을 선택한 보드 ID로 대응시킨다. 보드 회전·자유 배치·배경 그림 생성은 하지 않는다. 지형 표식과 연결선이 판정 기준이며 그림은 디지털 표현이다. 주제 지도 뒷면은 포함하지 않는다.
- 첫 플레이어가 정령 선택 전에 설정을 한 번 확정할 수 있다. 설정을 생략하면 기존 입문 설정이다. 일반 획득은 덱 4장 중 1장을 선택하며 주요 능력 획득 시 1장 망각한다. 입문 고정 획득 순서는 원래 저복잡도 4정령에만 적용한다.
- 오염 카드 없이 시작하면 공급은 인원×5+1개. 오염 카드를 쓰면 건강한 섬 공급 인원×2+1개, 소진 시 선택한 구성에서 숨겨 준비한 카드 1장을 공개한다. 쇠퇴의 소용돌이는 인원×5개, 먼지가 되는 기억은 인원×4개를 공급하며 매 침략 단계 시작에 현신 파괴/망각 효과를 적용한다.
- 대적: 브란덴부르크–프로이센·잉글랜드·스웨덴의 기본 단계와 1–6단계. 누적 효과, 침략 덱·공포 덱 구성, 단계 II 강화, 잉글랜드 추가 건설·건물 체력·수도 패배, 스웨덴 피해·추가 오염·다한 교체를 서버에서 처리한다.
- 시나리오: 전격전·섬의 심장 수호·공포의 의식·다한의 봉기. 변경된 준비·단계·승패를 적용한다. 심장 수호는 디지털 지도 배치에 맞춰 각 보드의 내륙 한 곳을 해당 플레이어가 선택한다(주제 지도/표준 물리 배치의 고정 번호와 다른 온라인 정책).

## CONFIRMED — 규칙 처리

- 에너지·카드·원소·현신 트랙, 성장→빠른 능력→공포→파괴→건설→탐험→느린 능력→시간 경과. 원소는 소비하지 않는다. 일반 구성에서는 빠른 능력을 느린 단계로 연기하지 않는다.
- 능력 대상은 해결 시 선택하고 사거리·지형·성소 조건을 서버에서 검증한다. 효과를 생략해도 카드 준비 비용은 환불하지 않는다.
- 녹음의 기본 성장과 현신 재생, 성소를 희생한 행동 차단, 고유 능력 반복을 처리한다. 천둥은 다한 이동에 현신을 동행시킬 수 있고 파괴로 다한을 잃으면 현신 희생을 선택한다. 추가 정령의 트랙 원소와 두 고유 능력은 별도로 표시·해결한다.
- 바다 정령이 있으면 각 보드에 바다 지역(번호 0)을 둔다. 그 보드에 바다 정령의 현신이 있을 때 능력/오염의 해안 습지로 활성화한다. 침략자 단계의 일반 대상에는 넣지 않는다. 익사는 기물을 파괴하고 침략자의 기본 체력을 인원수 단위로 자동 에너지 교환한다. 잔여 체력은 보존한다.
- 악몽 정령의 능력 피해는 별도로 누적하고 실제 기물 피해를 바꾸지 않는다. 가상 파괴는 공포와 밀기로 전환하며 한 능력에서 같은 침략자는 한 번만 처리한다. 다한 반격·공포 카드·시나리오 행동은 실제 피해다.
- 피해는 라운드 끝까지 유지한다. 방어는 땅과 다한 각각에 적용하며 생존 다한은 반격한다. 오염 연쇄·피해·이동·희생은 선택 대기 상태로 처리한다.
- 전격전의 빠른 비용 0 카드는 준비 시 에너지 1을 돌려받고 재선택 시 정확히 정산한다. 느린 단계는 유지하되 모든 능력을 빠른 단계에서 사용한다. 별도 신속화 여유가 있으면 느린 능력 첫 사용 시 자동 적용하여 에너지 1을 얻는다.
- 일반 승리는 공포 I 모든 침략자, II 모든 건물, III 모든 도시 제거 또는 마지막 공포 카드 획득. 오염 공급 소진·한 정령의 현신 전멸·침략 덱 소진 시 패배한다. 대적/시나리오의 추가 조건을 함께 적용한다.

## 온라인 정책과 상호작용

- 서버 권위, room 직렬화, 인증 actor·gameId·revision·단계 identity 검증, requestId 멱등성과 candidate 검증 후 원자 commit을 유지한다. 시간 제한이나 자동 전략 선택 없음.
- 동료 손패·사용 카드·원소·에너지는 공개한다. 미래 덱 순서, 공개 전 오염 카드, 개인 획득 후보는 숨긴다. 악몽으로 공개한 공포 카드만 위치·이름·공포 I–III 효과 설명을 공개한다.
- 일시 재접속은 기존 진행과 선택을 유지하며 명시적 나가기는 판 취소다. 서버 재시작 복구·영구 저장·공개 배포는 범위 밖이다.
- 클릭/터치/키보드 선택과 별도 확정을 사용한다. 단계별 안내, 비용·대상 안내, 현재 기물 기준 파괴 미리보기와 위험 표식을 제공한다. 미리보기는 판단 보조이며 서버 규칙 판정을 대체하지 않는다.
- 생성 일러스트로 정령·능력 테마·섬을 표현한다. 카드별 효과와 테마에 맞춰 일러스트를 배정한다. Web Audio 효과음은 사용자 제스처 이후 재생하며 정령별 능력 음색·음량·음소거·재접속 중복 방지를 지원한다.

### CONFIRMED — 가지와 발톱 보조 능력

- 확장 선택 시 보조 능력 31장을 기본판 보조 덱에 섞는다. 기본판은 확장 카드를 획득하지 않는다. 〈희생을 통한 성장〉을 포함한 가지와 발톱의 원래 카드 구성을 사용하며 다른 확장에 포함된 교체 카드는 이번 범위에 넣지 않는다.
- 오염 모으기는 이동이며 현신 파괴와 오염 연쇄를 일으키지 않는다. 비용 있는 제거는 실제 사용자의 에너지로 결제한다.
- 〈혼란을 일으키는 안개〉는 새 침략자의 추가에만 반응한다. 이동과 교체는 추가가 아니다. 근거: [공식 추가/교체 FAQ](https://querki.net/raw/darker/spirit-island-faq/.7w4gbfw).
- 〈해안까지 펼쳐진 하늘〉의 속도 변경은 한 번이며, 해안 사거리 보너스는 라운드 전체에 적용한다. 바람 조건을 충족한 〈땅을 쓸어버리다〉는 다른 속도 변경 횟수를 소비하지 않는다. 전격전에서는 해당 속도 변환의 에너지 환급을 적용한다([공식 FAQ](https://querki.net/raw/darker/spirit-island-faq/Blitz)).
- 〈교역을 부르는 소리〉는 공포 수준 II 이하에서 해당 지역의 첫 파괴를 건설로 바꾼다. 분쟁은 소비하지 않으며 바뀐 건설에는 질병과 건설 차단을 적용한다.
- 카드 비용·속도·사거리·원소·대상·효과는 가지와 발톱 카드 표기와 위 카드 사실 데이터로 대조했다. 한국어 제목과 설명은 이 앱의 자체 표기다.
- 능력 속도를 변경하면 해당 라운드의 반복에도 변경된 속도를 유지한다. 전격전에서도 하늘의 효과로 느린 단계에 사용하도록 바꿀 수 있다. 근거: [공식 속도/반복 FAQ](https://querki.net/raw/darker/spirit-island-faq/Sky%2BStretches%2Bto%2BShore).


### CONFIRMED — 가지와 발톱 주요 능력

- 확장 모드에 주요 능력 21장을 추가해 총 43장으로 구성한다. 기본판 주요 덱은 22장을 유지한다. 기존 카드 사실 데이터와 공식 FAQ를 대조하며 한국어 설명은 앱 자체 표기다.
- 〈불과 홍수〉는 같은 성소에서 서로 다른 두 지역을 고른다. 〈목을 조르는 불덩굴〉은 실제 출발 모래 지역에 야생을 놓으며 사거리 0이면 같은 지역에 두 개를 놓는다. 그림자의 사거리 무시도 출발 지형 제한은 유지한다([공식 대상 FAQ](https://querki.net/raw/darker/spirit-island-faq/Targeting)).
- 〈스스로 파멸하는 도구〉 기본 효과는 분쟁 침략자의 피해를 동시에 계산한다. 강화 효과는 파괴 피해를 인접 침략자에게 분배하며 분쟁·방어를 적용하지 않는다. 스웨덴의 파괴 피해 증가는 유지한다. 꿈 정령도 이 파괴 변환으로 실제 피해를 줄 수 있다([공식 FAQ](https://querki.net/raw/darker/spirit-island-faq/Instruments%2Bof%2Btheir%2BOwn%2BRuin)).

- 프랑스는 가지와 발톱에서 선택한다. 기본 단계부터 마을 총 공급은 인원당 7개이며, 추가·교체로 마을을 놓으려다 부족하면 그 사실을 보존해 행동 종료 시 패배/희생 승리를 판정한다. 제거·파괴·익사로 섬을 떠난 마을은 다시 공급에 포함된다.
- 단계 II 강화는 보드마다 표시된 지형 한 곳을 선택한다. 건물이 있으면 오염 1개, 없으면 마을 1개를 추가한다. 침략자 행동 생략으로 이 강화를 막지 않는다.
- 1: 준비 이후 건물이 없는 지역에 성공적으로 탐험하면 탐험가 +1. 2: 성공한 건설 후 탐험가가 2개 이상이면 하나만 남기고 마을로 교체하며 반란 카드를 이벤트 덱 네 번째에 넣는다. 3: 보드마다 마을 없는 최고 번호 지역과 지역 1에 마을 각 1개. 4: 해안 도시 건설 시 인접 지역 중 마을이 가장 적은 곳에 마을 +1. 5: 제거한 오염을 별도 보관해 인원당 3개가 모이면 전부 공급으로 돌린다. 6: 탐험 카드 해결마다 보드별 탐험가 없는 지역에 탐험가 +1. 공포의 탐험가 제거는 선택적 밀기로 바꾸지만 파괴는 그대로다.
- 반란은 프랑스 2단계 이상에서만 사용한다. 침략 I·II에는 보드마다 마을 하나에 분쟁 1, III에는 보드마다 마을 1 파괴·서로 다른 건물 2개에 분쟁 각 1 후 모든 침략자가 자신의 분쟁만큼 피해를 받는다. 다한 효과는 분쟁 침략자 각각에게 현재 다한 수만큼 피해를 주고, 이 효과로 파괴한 건물마다 다한 1개를 추가한다. 본문과 다한 효과 뒤 각각 승패를 확인한다.
- 반란 뒤 일반 이벤트를 하나 더 해결한다. I·II 반란은 다음 이벤트를 뽑은 뒤 덱 네 번째로 되돌리고 III 반란은 버린다. 침략 단계는 기존 이벤트와 같이 덱 맨 위 침략 카드로 정한다.

### 확장 시나리오 규칙 확인 (2026-09-14)

구현·검증 대상으로 확정한 원문은 [해안 수호](https://spiritislandwiki.com/index.php?title=Ward_the_Shores), [파괴하는 불꽃의 의식](https://spiritislandwiki.com/index.php?title=Rituals_of_the_Destroying_Flame), [오래전 잊힌 힘](https://spiritislandwiki.com/index.php?title=Powers_Long_Forgotten), [다음 물결](https://spiritislandwiki.com/index.php?title=Second_Wave)이다. 아래 규칙을 네 시나리오의 서버 판정과 화면에 반영했다. 검증 범위와 제한은 아키텍처 문서의 동일 날짜 기록을 따른다.

- 해안 수호: 정령별 라운드당 카드 하나를 원소 없는 비용 0·느린·사거리 0 능력으로 사용한다. 배치 시 오염과 건물 하나당 에너지 2를 지불한다. 표식은 방어 3, 오염 추가 시 파괴. 총 공급은 인원당 4개이며 기존 표식을 재사용할 수 있다. 기본 공포 구분선 아래 남은 공포 카드를 모두 추가한다. 일반 승리 대신 공포 II 이상과 모든 육지 해안의 수호가 필요하다. 침략 III단계의 탐험은 마을도 추가하며 프로이센의 조기 III 카드는 단계 II로 본다.
- 불꽃 의식: 모든 성장이 끝난 정령 단계에 각 정령이 불 원소 카드 하나를 망각하고 자기 현신 지역에서 의식한다. 영구 불꽃 표식과 오염 하나를 추가하고 현재 침략 단계만큼 에너지를 얻는다. 침략자가 있으면 같은 수의 공포와 다한 하나당 피해 1을 준다. 불꽃에서 거리 1 이내가 아니면 침략자에 대한 피해·파괴 및 그 대체 효과는 에너지 2를 지불해야 한다. 이벤트·공포·다한 반격도 적용되며 그 경우 어떤 정령이든 지불할 수 있다.
- 오래전 잊힌 힘: 번호 표식 인원+1개와 빈 표식 인원×3−1개를 섞어 보드당 다한 없는 지역 4곳에 놓는다. 다한 3개 또는 침략자 2개(프랑스는 3개)가 모이면 행동 도중에도 즉시 탐색한다. 정령은 발견 효과를 보류할 수 있다. 여덟 표식은 발견한 진영에 따라 서로 다른 효과를 가진다.
- 다음 물결: 승리한 섬의 다한·선택한 토큰·오염과 정령당 능력 하나를 이어받고 다른 정령으로 재시작한다. 같은 대적을 사용하며 건강한 섬에서 이겼으면 한 단계 높인다. 승계 능력은 침략 III에 진입한 뒤 정령 단계에 무료로 준비하고 원소를 제공하지 않는다. 이전 정령의 능력으로 취급하며 현재 정령의 현신이나 에너지를 사용하지 않는다. 10개 이하 원소 임계값을 충족한다. 공식 후속 물결 표는 7번째까지 제공된다.
