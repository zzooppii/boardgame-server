# 테라포밍 마스 후속 개발 작업

## 현재 완료 범위

- 타르시스 기본 지도, 2–5인, 기업시대 제외 프로젝트 137장, 기본 기업 10종과 초보자 기업.
- 기업·초기 카드 선택, 연구, 카드·일반 프로젝트·자원 전환, 업적·기업상, 생산, 마지막 녹지, 최종 정산.
- 서버 권위형 판정, 플레이어별 비공개 정보, 중복 요청 방지, 서버 실행 중 재접속과 선택 대기 복원.
- 오리지널 지형과 12장면 카드 일러스트, SVG 타일, 모바일·키보드 조작, 행동별 합성 효과음과 음량 저장.

아래 항목은 후속 개발 제안이다. 우선순위는 권장 순서이며, 확장·운영 정책은 아직 확정하지 않았다. 기존 검증 통과를 모든 카드 조합과 모든 기기에서의 검증 완료로 해석하지 않는다.

## 1순위 — 기본판 규칙·한국어 검수

- [ ] 공식 한국어판과 카드명·기업명·태그·효과 설명을 대조하여 용어를 통일한다.
- [x] 할인·이벤트 환급·도시 보상·채굴권·생태 태그 중첩 등 기업·카드 조합 7개 회귀 시나리오를 추가했다. 도메인 테스트는 총 24개이며, 모든 조합의 검수가 끝난 것은 아니다.
- [ ] 실제 3–5인 장기 플레이에서 연구 동시 제출, 효과 해결 중 연결 끊김, 마지막 녹지와 기업상 동점을 확인한다.
- [x] `e2e/mars.browser.test.mjs`에 두 참가자의 손패 검색·정렬, 키보드 배치, 재접속, 효과음·모바일 검증 시나리오를 추가했다. 실행 방법은 아키텍처 문서에 기록한다.

**완료 기준:** 카드·기업 용어 대조표, 검수한 조합별 기대값 테스트, 저장소에서 재실행 가능한 핵심 브라우저 시나리오. 발견한 차이는 규칙 문서와 함께 수정한다.

## 2순위 — 일러스트·UI·소리·상호작용 완성도

- [ ] 현재 태그별로 공유하는 12장면 일러스트를 카드·기업별로 더 구분되도록 확장한다. 우선 제작할 카드와 아트 방향부터 정한다.
- [x] 손패의 한국어·영어·효과 검색, 태그·종류·조건 필터, 할인 비용·이름 정렬과 낸 카드의 태그·지속 효과·미사용 행동 요약을 구현했다.
- [ ] 실제 휴대폰에서 카드 상세와 지도 배치를 번갈아 조작해 스크롤 거리·글자 크기·터치 영역을 조정한다.
- [x] 지불·배치·효과 선택 안내와 지불 후 잔량 미리보기, 서버 반영 후 자원·생산량·TR 변화 내역을 추가했다. 실제 기기에서의 가독성 평가는 남아 있다.
- [ ] 실제 스피커·이어폰에서 효과음 음량과 피로도를 청취 평가한다. 현재 브라우저 검증은 오디오 생성·음소거 동작 확인이다.
- [ ] Safari/iOS, Android, 키보드·스크린리더에서 오디오 활성화와 접근성을 확인한다.

**완료 기준:** 장기 대국에서도 카드와 행동을 쉽게 찾고, 실제 모바일에서 배치·취소·확정이 명확하며, 반복 효과음이 부담스럽지 않은 상태. 새 그림은 생성 기록과 파일 용량도 관리한다.

## 개발 제외 — 장기 대국 저장

사용자 요청에 따라 DB 저장, 서버 재시작 후 복구, 저장 상태 마이그레이션 개발을 제외한다. 현재 서버 실행 중 재접속 기능은 유지한다.

## 3순위 — 선택 규칙과 확장

| 후보 | 먼저 결정할 사항 | 구현·검증 범위 |
| --- | --- | --- |
| 기업시대 | 기본판과 선택 모드 구분 | 추가 카드·기업, 초기 생산 규칙, 기존 카드와 조합 |
| 프렐류드 | 적용 판본과 기업시대 조합 | 초기 선택·효과 해결, 시작 상태 검증 |
| 추가 지도 | 도입할 지도 순서 | 배치 칸·보너스·업적·기업상 데이터 분리 |
| 드래프트 | 첫 세대 적용 여부·전달 방향 | 비공개 카드 전달, 동시 선택·재접속 |
| 솔로 | 사용할 공식 변형과 승리 조건 | 전용 초기 상태·세대 제한·종료 판정 |
| 시간 제한 | 제한 단위와 만료 시 정책 | 서버 시계·스케줄러, 강제 처리·재접속 |

**완료 기준:** 선택한 규칙을 먼저 문서에서 확정한 뒤 구현한다. 확장 미선택 시 현재 기본판 동작을 유지한다.

## 공통 플랫폼 후속 과제

- 공통 앱 번들의 500kB 초과 경고 개선. 마스 화면·CSS는 이미 지연 로딩하지만 공통 번들은 별도 분석이 필요하다.
- 이 항목은 여러 게임에 영향을 주므로 마스 카드 추가와 분리해서 진행한다.

## 권장 다음 작업

**한국어 용어 검수와 기업·카드 조합 회귀 테스트 → 실제 모바일·청취 평가 → 기업시대** 순서를 권장한다. 카드별 일러스트 제작은 용어와 카드 목록을 확정한 뒤 독립적으로 진행할 수 있다.
