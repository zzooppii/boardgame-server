# 테라포밍 마스 후속 개발 작업

2026-09-17 기준. 이 문서는 현재 남은 작업을 정리한다. 이전 단계의 카드 조립 수량·미연결 상태는 현재 미완료 목록이 아니다. 구현 이력과 당시 검증 결과는 [아키텍처](TERRAFORMING_MARS_ARCHITECTURE.md), [기업시대](TERRAFORMING_MARS_CORPORATE_ERA.md), [프렐류드](TERRAFORMING_MARS_PRELUDE.md)에 기록한다.

## 구현 완료 범위

- 타르시스 지도, 2–5인, 초기 기업·프로젝트 선택, 연구, 카드·일반 프로젝트·자원 전환, 업적·기업상, 생산, 마지막 녹지, 최종 점수.
- 기업시대와 프렐류드를 시작 전에 방장이 개별 선택. 참가자에게 설정을 표시하고 시작 후 고정.
- 기본 프로젝트 137장, 기업시대 포함 208장, 프렐류드 추가 프로젝트 7장·프렐류드 35장·추가 기업 5종.
- 서버 권위형 판정, 비공개 선택, 중복 요청 방지, 서버 실행 중 재접속과 진행 중 선택 복원.
- 한국어·영어 이름, 카드 인쇄 조건·실제 비용, 지불 자원 조합·잔량, 손패 검색·필터·정렬.
- 지도 방향키·Home/End·별도 배치 확정, 모바일 영역 이동, 미사용 카드 행동 바로가기.
- 자원·생산량·TR·카드 자원 증감 안내, 행동별 합성 효과음과 음량·음소거.
- 오리지널 지형·12장면 카드 일러스트·SVG 타일. 카드별 고유 일러스트까지 완료한 것은 아니다.

## 남은 작업과 권장 순서

- 프렐류드 해양 배치 시간 초과 원인 확인: 테스트가 이전 화면의 첫 후보 요소를 기다리던 문제였다. 고정 시드 11로 실패를 재현하고 서버 후보의 칸 ID를 지정하도록 수정했다. 게임 UI·판정 변경 없음.
- 검증 완료: 같은 시드에서 Chrome 3회 연속 통과, 해양 두 칸 commit 확인. 격리 복사본 타입 검사·빌드·테스트 5,537개 통과. 종료 전 진단 파일과 캡처를 저장하도록 개선.

| 순서 | 작업 | 다음 실행 내용 | 완료 확인 |
| --- | --- | --- | --- |
| 1 | 후반부 UI·접근성 검수 | 검색·인쇄 태그·정렬·목록·초점 복귀는 구현됨. 실제 많은 카드가 쌓인 대국에서 긴 문구·초점·스크롤을 추가 검수 | 자동 브라우저 검사와 실제 조작 평가, 발견한 문제의 회귀 테스트 |
| 2 | 카드·기업 일러스트 차별화 | 카드 8장·기업 4곳 전용 그림 제작. 나머지 같은 그림을 공유하는 카드군과 기업별 그림을 순차 제작 | 카드 식별성·문자 대비·모바일 축소·자산 용량 확인 |
| 3 | 실제 다인 플레이·한국어판 검수 | 3–5인 장기 대국에서 효과 연쇄·기업상 동점·최종 녹지·안내 명확성 확인, 실물 카드명·용어 대조 | 판본과 재현 절차를 남기고 확인된 차이 수정 |
| 4 | 브라우저·기기·소리 검수 | Safari/iOS·Android, 스크린리더, 스피커·이어폰의 오디오 활성화·반복 음량·터치·스크롤 확인 | 실제 환경별 결과와 미지원 항목 기록 |

다음 코드·자산 작업은 많은 카드가 쌓인 화면의 재현 검수와 전용 그림 확대다. 3·4번은 실제 참가자·실물·기기를 통한 평가가 필요하다. 추가 지도·드래프트·솔로는 아래 별도 결정 범위다.

자동 검증 통과는 실제 사람의 장기 플레이, 공식 한국어판 실물 대조, 실기기·청음 평가를 대신하지 않는다. 공개 자료를 통한 한국어 대조는 수행했지만 실물 전체 검수는 남아 있다. 발견되지 않은 모든 카드 조합의 정확성을 보증하는 상태도 아니다.

## 이후 선택 가능한 확장 — 미확정

다음 항목은 현재 구현 약속이 아니며 적용 범위·규칙을 정한 뒤 별도 개발한다.

| 후보 | 먼저 결정할 사항 |
| --- | --- |
| 추가 지도 | 지도 종류, 배치 칸·보너스·업적·기업상 |
| 드래프트 | 첫 세대 적용 여부, 전달 방향, 동시 선택 정책 |
| 솔로 | 적용 변형, 초기 상태, 세대 제한과 승리 조건 |
| 시간 제한 | 제한 단위, 만료 시 강제 처리와 재접속 정책 |

기업시대·프렐류드는 이 미확정 후보에서 제외한다. 두 확장은 이미 시작 전 선택 가능한 모드다.

## 개발 제외 — 장기 대국 저장

사용자 요청에 따라 DB 저장, 서버 재시작 후 복구, 저장 상태 마이그레이션은 개발하지 않는다. 현재 서버 실행 중 재접속 기능은 유지한다.

## 공통 플랫폼 별도 과제

공통 앱 번들의 500 kB 초과 경고는 남아 있다. 마스 화면·CSS는 지연 로딩한다. 공통 번들 최적화는 여러 게임에 영향을 주므로 별도 범위로 진행한다.
