# 아르낙 브라우저 자동 검증

`e2e/arnak.browser.test.mjs`는 실제 Chrome과 실제 Socket.IO 서버를 사용한다. 게임 상태, 서버 행동 목록, 난수 결과를 주입하거나 모의 응답으로 대체하지 않는다. 모든 게임 명령은 화면의 버튼과 확정 패널을 통해 보낸다.

## 실행

기존에 설치된 Playwright와 Chrome을 사용한다. 저장소에 dependency를 추가하지 않았으며 환경변수로 실행 환경을 지정한다. 이 테스트는 브라우저가 없는 기본 `npm test`와 별도로 실행한다.

1. 루트에서 `npm run build`를 실행한다.
2. 별도 터미널에서 일회성 로컬 서버를 시작한다. 운영 서버나 기존 게임에 연결하지 않는다.

```sh
node --input-type=module -e 'import {createHttpServer} from "./apps/server/dist/server.js"; const s=createHttpServer({serveWeb:true}); s.httpServer.listen(3026,"127.0.0.1"); process.on("SIGINT",async()=>{await s.shutdown();process.exit(0)});'
```

3. 설치 경로를 지정하고 테스트를 실행한다.

```sh
ARNAK_BROWSER_URL=http://127.0.0.1:3026 \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
ARNAK_CHROME_PATH='/absolute/path/to/chrome' \
npm run test:arnak-browser
```

Playwright가 일반 모듈 경로에서 해석되면 `PLAYWRIGHT_MODULE`은 생략할 수 있다. Playwright에 설치된 Chromium을 사용하는 경우 `ARNAK_CHROME_PATH`도 생략할 수 있다. URL은 localhost/127.0.0.1/::1만 허용한다. 테스트 종료 후 서버 터미널에서 Ctrl+C로 종료한다.

## 검증 내용

- 새 브라우저 context 두 개: 데스크톱 1440×1000, 모바일 390×844. 기존 사용자 프로필·자격 증명을 사용하지 않는다.
- 화면에서 방 생성, 초대 코드로 참가, 게임 시작 및 손패 5장 확인.
- 실제 발굴 효과음의 오실레이터 시작 관찰, 음소거 후 미리 듣기 비활성화와 음량 저장 확인. 게임이나 오디오 동작을 대체하지 않는다.
- 시작 카드 확대, Escape 닫기와 초점 복귀, 자금 지원 사용 후 금화 증가·손패 감소.
- 새로고침 후 야영지 상태·기록 복원 및 과거 자원 알림 재생 방지.
- 양쪽 플레이어의 실제 발굴·탐험가 감소, 차례 종료, 패스, 보관 선택과 정확한 카드 인스턴스의 복원.
- 1~5라운드 진행, 결과 화면의 양쪽 승자 문구·총점 일치, 점수 비교표 7항목, 게스트의 재경기 권한 무표시.
- 방장 재경기 준비 후 새 1라운드·손패 5장·빈 기록 확인.
- 재경기에서 시작 카드 사용 → 고대 제단 발굴 → 상대 패스 → 1L 돋보기 연구 → 해안 야영지 발굴 → 아이템 구매를 실제 조작으로 진행.
- 연구 안내의 비용·보상, 나침반/화살촉 차감, 금화 보상, 양쪽 화면의 연구 말 이동과 새로고침 복원 확인.
- 아이템 가격만큼 금화 차감, 손패 유지·덱 1장 증가, 양쪽 교역소에서 구매 카드 제거, 새로고침 후 구매 결과 유지와 차례 종료 후 교역소 보충 확인.
- 다음 라운드에서 나침반 확보 → 1단계 유적 발견 → 우상 획득·탐험가 배치 → 무작위 추가 보상 처리 → 수호자 등장 확인. 추가 선택이 발생하면 새로고침 후 동일한 선택 단계 복원을 검사한다.
- 두 참가자 화면의 발견 장소·수호자 이름·5점 표시·극복 비용 안내 일치, 발견 후 새로고침 복원 확인.
- 수호자를 남겨 두고 라운드를 종료하면 총 보유 카드 수가 정확히 1장 증가하고 탐험가가 복귀하며, 수호자는 지도에 남는지 확인. 이 구간에는 다른 카드 획득·제거 행동을 하지 않는다.
- 공개된 수호자 비용에 맞춰 우상 슬롯·기본 장소를 사용하고 재방문해 극복. 확정 패널의 실제 자원/카드 지불과 결과 차감 일치, 양쪽 지도에서 수호자 제거, 내 야영지의 5점·축복 표시와 새로고침 복원을 검사한다.
- 축복 사용 및 후속 선택 처리 뒤 5점 유지·사용 완료 표시를 확인하고, 다음 라운드에 공포 카드가 추가되지 않는지 검사한다.
- 최대 두 라운드 동안 나침반을 모아 실제 교역소 유물을 구매. 표시 가격과 확정 비용 일치, 구매 즉시 사용한 카드 더미 편입, 양쪽 교역소에서 제거, 새로고침 후 후속 효과 처리, 차례 종료 후 교역소 보충을 확인한다.
- 선택한 유물이 자원 획득·드로우·공포만으로 구성된 자동 효과라면 인쇄된 문구와 실제 자원·총 카드 수 변화를 대조한다. 복합 효과는 후속 선택 종료와 구매 상태 복원을 검증하며 모든 효과의 수치를 재계산하지 않는다.
- 모바일 문서 가로 넘침과 브라우저 pageerror 검사.

첫 대국 최대 100회의 진행 단계, 발견 보상 최대 12회, 수호자/유물 후속 효과 최대 16회 선택과 전체 240초의 시간 제한을 둔다. 테스트용 서버에만 새 방을 만들며 브라우저 context는 성공/실패 시 닫는다. 임시 폴더에 데스크톱·모바일 결과 화면과 연구·구매 후 화면, 유적 발견 후 화면, 수호자 극복·유물 구매 후 화면을 저장하고 경로를 테스트 출력에 남긴다. 실패 시 각 브라우저의 화면과 UI 텍스트도 기록한다. 세션 토큰·localStorage 전체·네트워크 payload는 진단에 출력하지 않는다.

## 범위와 한계

기본판 전체를 끝내는 UI 회귀 시나리오다. 전략적 플레이 또는 모든 카드 조합의 검증은 아니다. 기본 장소 발굴, 시작 카드, 1단계 돋보기 연구, 아이템 구입, 유적 발견, 수호자 극복·축복 및 공포 처리, 유물 구매를 포함한다. 발견 보상은 실제 무작위 결과를 처리하므로 한 실행이 모든 보상 종류를 검증하지는 않는다. 모든 수호자·유물 효과 조합, 고급 연구·중간 선택의 모든 조합, 3~4인 복합 행동 조합, 패킷 유실/오프라인 복구는 별도 확장 대상이다. 기존 아르낙 domain·Socket.IO 테스트는 계속 유지한다.

## 3~4인 대국

동일 실행 명령은 3인·4인 시나리오도 순서대로 실행한다. 각 시나리오는 새 방과 참가자별 독립 브라우저 context를 사용하며 마지막 참가자는 390px 모바일 화면이다.

- 모든 참가자가 첫 라운드에 자금 지원을 사용하고, 매 라운드 서로 다른 기본 장소를 발굴한 뒤 패스해 5라운드를 완료한다. 3인은 70회, 4인은 91회 명령을 실제 확정한다.
- 3인 기본 장소 차단 슬롯 3개, 4인 차단 없음, 참가자별 상대 캠프 수를 확인한다.
- 차례 순서, 차례 종료 후 다음 참가자로 이동, 정리 중 차례 유지, 매 라운드 선 플레이어 한 자리 교대를 검사한다. 차례가 아닌 참가자에게 행동 찾기 목록이 나타나지 않아야 한다.
- 2라운드에서 비활성 참가자를 새로고침해 손패·자원·진행 상태를 복원하고 현재 차례가 바뀌지 않는지 확인한다.
- 모바일 참가자는 2라운드에 돋보기, 3라운드에 수첩을 1L로 이동한다. 탐험 카드와 고대 제단으로 자원을 확보하며 비용 차감과 전원 화면의 말 위치를 검사한다.
- 수첩 보상으로 공개 조수 3명 중 한 명을 고용한다. 선택 중 차례 종료 불가, 새로고침 후 동일 선택지 유지, 고용 후 공급 더미 제거와 은색·준비 상태, 상대 공개 캠프 반영, 고용 후 새로고침 복원을 검사한다.
- 전원에게 연구를 진행한 참가자의 승리와 같은 점수표가 표시되고 결과 카드 수가 참가자 수와 같아야 한다. 게스트의 재경기 버튼 무표시, 모바일 문서 가로 넘침, pageerror도 검사한다.

각 다인 시나리오는 180초 제한이며 실패 시 UI 텍스트와 화면을 남기고 브라우저를 정리한다. 다인 테스트는 차례·라운드·동기화 회귀 범위다. 복잡한 카드 상호작용과 모든 자원/연구 조합을 다인으로 검증한 것은 아니다.
