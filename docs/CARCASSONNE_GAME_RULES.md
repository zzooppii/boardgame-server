# 카르카손 기본판 규칙과 온라인 정책

2026-09-11. 사용자가 전체 개발과 일러스트·UI·소리를 요청한 범위에 따라 기본판을 구현한다. 이전 제안의 2–5인, 농부 포함, 90초 턴·시간 초과 시 타일만 자동 배치를 채택한다. 다음은 이번 구현의 기준이며 기존 게임의 미확정 규칙은 바꾸지 않는다.

## 근거

- [공식 기본 규칙](https://www.hans-im-glueck.de/wp-content/uploads/2024/11/Carcassonne-v3_Rulesheet_EN_web.pdf): 배치→선택적 미플→정산, 완성/미완성 점수.
- [공식 보충 규칙](https://www.hans-im-glueck.de/wp-content/uploads/2024/11/Carcassonne-v3_Supplement_EN_web.pdf): 농부와 들판, 도시당 3점, 공동 최다 미플.
- [출판사 공식 Big Box 2010 설명서](https://cundco.de/media/84/a4/ac/1773930056/CC_BigBox_2010_Rule.pdf?ts=1773930056), 부록 B1(PDF 17쪽): A–X 24종 72장 카탈로그를 렌더링하여 수량과 연결 모양을 직접 대조했다. 기본 72장만 사용하며 Big Box의 6번째 색과 확장 타일은 사용하지 않는다.
- [공식 제품](https://www.hans-im-glueck.de/en/game/carcassonne/): 기본판 2–5인.

## CONFIRMED — 원작 규칙

- A–X 수량은 2,4,1,4,5,2,1,3,2,3,3,3,2,3,2,3,1,3,2,1,8,9,4,1이다. D 한 장을 (0,0)에 두고 나머지 71장을 섞는다. 배치용 미플은 각 7개다.
- 타일은 0/90/180/270도로 회전한다. 기존 보드의 한 변 이상과 인접해야 하고 모든 인접 면의 도시·도로·들판이 맞아야 한다. 대각선 인접만으로는 배치할 수 없다.
- 합법 위치가 하나도 없는 타일은 게임 밖으로 버리고 새 타일을 뽑는다. 서버가 모든 회전과 인접 빈칸을 확인한다. 남은 타일이 모두 배치 불가라면 마지막 정산 후 종료한다.
- 새 타일의 구역 하나에 미플 하나를 놓거나 생략한다. 연결된 전체 구역에 누구의 미플도 없어야 한다. 완성될 영역에도 새 미플을 먼저 놓고 정산할 수 있다. 같은 턴 정산으로 회수할 미플을 미리 재사용할 수 없다.
- 도시·도로는 타일 내부의 구역 연결과 이웃 타일 연결을 함께 탐색한다. 교차로의 각 도로는 별도 도로다. 따로 점유한 구역이 후속 타일로 합쳐지는 것은 가능하다.
- 완성 도로는 고유 타일당 1점, 완성 도시는 고유 타일과 방패마다 2점이다. 같은 타일의 여러 구역이 하나로 연결되어도 타일은 한 번만 센다. 수도원은 자신과 주변 8칸이 차면 9점이다.
- 각 구역에서 미플 최다 플레이어가 전체 점수를 받으며 공동 최다는 각각 전체 점수를 받는다. 완성한 도시·도로·수도원의 모든 미플을 돌려준다. 한 배치로 완성한 모든 구역을 정산한다.
- 농부는 게임 중 돌아오지 않는다. 들판은 도로·도시로 나뉜다. 최종 정산에서 해당 들판과 접한 완성 도시마다 3점이며 같은 도시는 해당 들판에서 한 번만 센다. 서로 다른 들판은 같은 도시를 각자 셀 수 있다.
- 최종 미완성 도로는 고유 타일당 1점, 미완성 도시는 고유 타일·방패당 1점, 수도원은 자신과 주변의 실제 타일 수만큼 점수다. 들판까지 정산하여 최고 총점이 승리하며 동점이면 공동 승리다.

## CONFIRMED — 온라인 정책

- 서버가 선을 무작위 선택하고 참가 순서를 순환한다. 방장·전원 접속·2–5인 조건으로 준비 버튼 없이 시작한다.
- 턴마다 서버 Clock 기준 90초. 마감 이상인 수동 명령은 거부한다. 자동 배치는 중심으로부터 거리→y→x→회전 순의 첫 합법 위치에 미플 없이 놓는다. 점수 최적화나 비공개 덱을 이용하지 않는다.
- 타일 위치·방향·선택적 미플은 클라이언트 미리보기이며 한 명령에서 원자적으로 확정한다. 확정 전 수정/취소는 자유롭다. 확정 후 되돌리기는 없다.
- 현재 뽑은 타일·보드·미플·점수·남은 개수·버린 공개 타일은 모두 공개한다. 미래 덱의 순서·타일 ID는 모든 클라이언트에서 비공개다.
- 연결이 끊겨도 시간은 흐른다. 새로고침은 같은 게임·차례·보드로 복귀한다. 명시적인 나가기는 게임을 CANCELLED로 종료하며 승자를 만들지 않는다. 종료 후 같은 방 재시작/게임 교체와 기존 방장 승계를 지원한다.
- 효과음은 사용자 조작으로 시작하며 볼륨·음소거를 저장한다. 중복 snapshot과 최초 재접속에서 과거 점수·배치음을 재생하지 않는다.

## TO_BE_CONFIRMED — 후속 범위

강·수도원장 및 다른 확장, 제한 시간 선택, AI 상대, 관전, 누적 전적, 서버 재시작 후 지속 복구는 이번 구현에 포함하지 않는다.

## CONFIRMED — 여관과 성당 / 상인과 건축가 (2026-09-16)

사용자가 두 확장을 방장 선택 방식으로 추가하도록 요청했다. 기존 기본판과 동일한 공식 Big Box 2010 설명서 6–8쪽 및 부록 B1/B2를 기준으로 한다. 두 확장은 독립 선택·동시 사용 가능하며 기본값은 모두 꺼짐이다. 기존 온라인 정원 2–5인과 90초 정책을 유지한다. 실물의 6번째 색과 점수판 표식은 이번 온라인 확장의 별도 기능으로 추가하지 않는다.

- 여관과 성당: EA–EQ 18장(EK 성당 2장), 큰 미플 각 1개. 여관 도로는 완성 시 타일당 2점, 성당 도시는 완성 시 타일·방패당 3점. 미완성은 각각 0점이며 같은 시설이 여러 개 있어도 배율은 누적하지 않는다. 큰 미플은 점유 비교에서 2명이며 배치·회수·농부 규칙은 일반 미플과 같다.
- 상인과 건축가: HA–HX 각 1장, 포도주 9·곡물 6·직물 5, 건축가·돼지 각 1개. 상품 도시는 점유와 무관하게 해당 도시를 완성한 플레이어에게 상품을 준다. 각 상품 최다 보유자는 종료 시 10점, 공동 최다는 각각 10점. 아무도 얻지 못한 종류는 보너스를 주지 않는다.
- 건축가는 자기 일반/큰 미플이 있는 도시·도로의 새 타일에 배치한다. 이후 자기 건축가가 있던 영역을 연장하거나 완성하면 추가 타일 1장과 배치 기회를 얻는다. 건축가를 처음 놓은 턴에는 발동하지 않고 추가 턴에서 다시 연장해도 세 번째 턴은 없다. 완성으로 회수되어도 이미 얻은 추가 턴은 유지된다. 추가 턴에도 새 turnId와 90초 서버 마감을 적용한다. 덱이 소진되면 즉시 최종 정산한다.
- 돼지는 자기 농부(일반/큰 미플)가 있는 들판의 새 타일에 배치하며 종료까지 남는다. 들판 최다 점유자 중 자기 돼지가 있는 플레이어만 완성 도시당 4점, 다른 공동 최다 플레이어는 3점이다. 건축가와 돼지는 점유 수에 포함하지 않는다. 한 타일에는 일반·큰 미플·건축가·돼지 중 하나만 새로 배치한다.
- ED/HJ 수도원은 도로를 각각 2/3개로 분리한다. EI 교차로의 두 짧은 도시 진입선은 배치 가능한 도로가 아니다. EC 여관은 동쪽 도로에만 속한다. HB/HC 다리는 교차로가 아니며 도로를 서로 연결하지 않는다. EH/HM의 도시와 EG의 안쪽 들판은 별도 영역이다.
- 방장만 LOBBY에서 scoped room revision을 검증하는 설정 명령으로 확장을 변경한다. 시작 후 변경 불가, 재접속 시 서버 설정을 복원한다. 기본 72장 / 여관 90장 / 상인 96장 / 양쪽 114장의 정확한 재고와 특수 말 보존을 서버가 검증한다.
