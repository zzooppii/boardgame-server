# 아크노바 규칙과 구현 범위

상태: WEB_CONNECTED / VALIDATION_IN_PROGRESS. 전체 기본판 솔로를 실제 서버 방과 웹 화면에 연결했고 준비부터 27턴·5회 휴식·최종 정산까지 브라우저 완주를 확인했다. 카드별 효과·예외·최종 점수와 설명의 일치 여부는 계속 검증하고 있다. 아래 CONFIRMED는 규칙 결정이며 전체 구현 검증 완료를 뜻하지 않는다. 최신 구현과 검증 기록은 [구현 경계](./ARK_NOVA_ARCHITECTURE.md)에 정리한다.

- 지도 A의 지원 토큰 7개는 스냅 1/무료 2칸 우리/돈 5/보전 1(즉시 및 휴식마다), 평판 2/돈 12/X 3(일회성)을 활성화한다. 지원 보상과 지도 보너스의 처리 순서는 선택한다(규칙서 6·15쪽, Icon Overview). 공개 프로젝트는 솔로에서 최대 2장이며 새 카드가 들어오면 가장 오래된 카드를 버리고, 그 지원 토큰은 지도 보너스로 돌려놓지 않는다.
- 이주 기록(224)을 플레이한 경우 방사 프로젝트를 지원할 때마다 보전 1을 추가로 얻고, 같은 방사 프로젝트의 다른 빈 칸을 별도 협회 행동에서 다시 지원할 수 있다. 이미 점유한 칸 재사용과 일반/번식 프로젝트 반복 지원은 허용하지 않는다. 각 지원은 종료 점수 조건에서 별도 지원 횟수로 센다. 새 카드로 놓을 때의 평판 1은 반복 지원 시 다시 얻지 않는다(Glossary 1·5쪽, 규칙서 15쪽의 빈 조건 칸 요구).
- 주머니 능력이 있는 동물을 방사하면 해당 동물 밑의 카드들도 버린다. 이전에 주머니로 얻은 매력은 유지하며 방사 시 동물에 인쇄된 매력만 잃는다(Glossary 3쪽 Pouch).
- 번식 협력(215)·번식 프로그램(218)은 각각 자기 카드의 토큰 1개를 기본 프로젝트 지원의 아이콘 1개로 대체할 수 있다. 각 카드에서 한 번에 최대 1개이므로 두 후원 카드를 모두 플레이했다면 각각 1개씩 사용할 수 있다. 이 효과의 기본 프로젝트는 협회 보드 아래 카드만 의미하며, 손패에서 새로 낸 기본 프로젝트 카드에는 적용하지 않는다. 서버는 선택한 후원 카드의 소유·플레이 여부와 남은 토큰, 프로젝트 위치를 검사하고 지원 성공 시에만 토큰을 차감한다(Glossary 5쪽 215, 218의 215 참조).
- 기술자(217)는 건설 행동마다 그 행동으로 지은 건물 종류 중 하나를 정확히 한 번 더 지을 수 있다. 추가 건물은 정상 비용과 배치 규칙을 적용하되 행동 강도는 추가로 쓰지 않는다. 특수 우리(어린이 동물원·파충류관·대형 조류관)는 이 효과로 중복 건설할 수 없다. 건설 I/II 모두 적용하고, 여러 종류를 지어도 추가 건설은 행동당 1회다(Glossary 5쪽 217, 강도 4로 1칸 매점·1칸 우리·2칸 우리와 추가 2칸 우리를 짓는 예시).
- 고고학자(221)는 건설로 가장자리 칸의 배치 보너스를 얻을 때마다 아직 덮이지 않은 배치 보너스 하나를 추가로 받는다. 고르는 칸은 가장자리가 아니어도 되고, 추가 보너스가 여러 개라면 같은 칸을 여러 번 골라도 된다. 선택한 칸을 덮거나 보너스를 소모하지 않으며, 추가 보너스 선택은 새로운 건설이 아니므로 고고학자를 재발동하지 않는다. 모든 보너스의 순서는 선택한다(Glossary 5쪽 221).
- 수문학자(241)·지질학자(242)는 각각 물·바위에 인접한 새 건설 칸마다 돈 1을 준다. 같은 칸이 해당 지형 여러 칸에 닿아도 카드별로 1만 받고, 한 건물의 여러 칸은 각각 센다. 지도 배치 보너스와 별도 효과로 처리한다(Glossary 6쪽 241/242).
- 다양성 연구자(219)를 플레이하면 일반·무료 건설에서 물과 바위 칸을 덮을 수 있다. 비용·연결·점유·건설 II 필요 칸 등 다른 제약은 유지한다. 덮인 물과 바위는 수문학자·지질학자 수입과 해당 최종 지형 점수에서 제외하며, 동물원 전체를 덮는 조건에는 여전히 물·바위를 덮을 필요가 없다(Glossary 5쪽 219).
- 소형 동물 프로그램(228)은 동물 행동에서 적어도 한 마리를 사용하고 모두 소형 동물이었다면 손패의 소형 동물 한 장을 정상 비용과 조건으로 추가 사용하게 한다. 추가 사용은 포기할 수 있으며, 그 후 시장에 소형 동물이 있으면 평판 범위와 무관하게 한 장을 손패에 넣는다. 원래 행동에 중형·대형 동물이 섞였으면 발동하지 않는다. 추가 동물의 즉시 효과를 먼저 해결하고 시장 선택 후 행동 카드를 이동하여 행동 종료 후 효과를 처리한다. 소형은 표준 우리 크기 1·2 또는 어린이 동물원 동물이다(Glossary 6쪽 228).

- 후원자 종료 보너스(공식 Glossary 4–5쪽): 203·209는 대학 3개면 보전 1, 210은 매점 5개 이상이면 보전 1, 211은 점유된 1칸 우리 5개 이상이면 보전 1, 214는 보유 X마다 매력 1, 216·220은 평판 9 이상이면 보전 1, 217은 지도 땅 전체를 덮으면 매력 5, 219는 물·바위 아이콘 한 쌍마다 매력 2(최대 6), 221은 가장자리 땅 전체를 덮으면 보전 1. 전체 덮기에서 물·바위 칸은 제외한다. 종료 점수는 새 트랙 보너스를 발동하지 않는다.

- 초기 선택 → 행동 → 추가 선택 → 턴 종료 → 휴식 → 마지막 턴 → 최종 정산: 현재 연결 명령으로 27턴과 3개 난이도의 상태 저장/복원 검증을 추가했다. 다섯 기본 행동과 카드·프로젝트를 사용하는 실제 방·화면 완주도 확인했다. 모든 효과 종류와 예외의 검증은 별도로 추적한다.
- 같은 시점의 효과 처리 순서 선택, 행동 후 효과의 지연 처리.
- 지도 경계·물·바위·기존 건물·회전·반전·업그레이드 필요 칸.
- 카드별 원본 수치·조건·효과와 서버 구현 대응.
- 다른 사람 손패 참조·중복 요청·오래된 revision·재접속·무변경 실패.

## 효과 처리 구현 근거 보강

- 규칙서 11쪽: 동물 카드를 한 장씩 조건 검사·선지불·입주·효과 순으로 처리한다. 즉시 효과와 다른 카드의 반복 효과는 순서를 선택할 수 있고, 첫 동물의 즉시 효과를 끝내야 다음 동물을 낸다. 마지막에 동물 행동 카드를 1번 칸으로 옮긴 뒤 행동 종료 후 효과를 해결한다.
- 규칙서 13쪽: 동물 II의 강도 5 이상 평판 1은 행동 시작 때 선택적으로 받는다. 이후 시장 접근 범위에 반영한다.
- Glossary 2–3쪽과 기본판 카드 설명: 땅파기는 한 장마다 시장 버림/즉시 보충 또는 손패 버림/덱 드로우를 선택하며 표시 횟수 이내에서 중단할 수 있다. 후원자 유치는 평판 범위와 무관하게 시장의 후원 카드 전부를 가져오며 행동 종료까지 시장 구멍을 유지한다. 스냅 2회 사이의 시장 보충은 선택이다.

- 규칙서 12쪽: 대형 조류관/파충류관을 지은 직후 한 번만 기존 동물을 옮길 수 있다. 각 동물의 물/바위 조건과 특수 우리 용량을 만족해야 하며, 조건을 만족하는 가장 작은 점유 표준 우리를 비운다. 해당 지형 조건의 우리가 없으면 크기를 만족하는 가장 작은 점유 우리를 비운다. 여러 동물은 각각 이동 여부를 선택한다. 무료 건설의 지도 보상은 다음 건물을 놓기 전에 해결한다.

- 공식 FAQ v2: 무료 제휴/대학은 일반 공급이 아닌 협회 보드에서 가져온다. 무료 제휴라도 세 번째/네 번째 칸에는 협회 II가 필요하다. 보너스가 행동 업그레이드 필요 지도 칸을 해금하지 않는다.
- 공식 FAQ v2 정오표: 방사/특수 우리 이동에서 크기를 만족하는 점유 우리가 전혀 없으면 아무 우리도 뒤집지 않는다. 휴식의 카드 수입 후 플레이어별로 시장을 보충한다. 솔로는 한 플레이어의 수입 선택을 끝낸 뒤 보충한다.
- 후원 260의 가장자리 연결 즉시 매력에는 물·바위 칸을 포함하지 않는다. 아직 건설 II로 해금하지 않은 땅은 포함한다(FAQ v2 1쪽).

- 보전 5·8점은 돈 5 또는 해당 칸에 남아 있는 보너스 타일 하나 중 택1이다. 돈 5가 타일에 추가로 지급되지는 않는다. 선택한 타일은 제거하며, 돈을 선택하면 타일은 유지한다. 최초 배치는 각 칸에 서로 다른 타일 2개다(규칙서 18쪽). 점수판은 남은 타일을 각각 오각형과 효과 설명으로 표시하고, 현재 효과 화면에서 같은 설명을 보고 선택한다.

- 카드 사용 선택 단계 취소: 아직 카드를 사용하지 않고 시작 보상을 받지 않은 일반 동물/후원자 행동은 서버가 저장한 X 지불량을 환급하고 행동 선택으로 돌아간다. 턴·행동 카드 위치는 유지한다. 이미 사용한 카드·공개 정보·보상, 반복/추가 행동은 되돌리지 않는다. 사용자 요청(2026-09-15)에 따른 선택 단계 UX이며 실행한 행동의 되돌리기는 제공하지 않는다.
