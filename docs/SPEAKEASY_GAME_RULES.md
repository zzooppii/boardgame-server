## CONFIRMED

- 준비 라운드(1920): 차례 역순으로 진행한다. 2인은 먼저 각자 공급의 조직원 1명을 빈 부두 칸에 역순으로 놓고 그 칸 보너스를 받는다. 이어 각 플레이어는 역순으로 주점 또는 증류소 1개를 초기 현금에서 비용을 내고 빈 건물 칸에 놓는다. 다른 플레이어 건물이나 마피아 주점이 있는 칸에는 놓지 않는다. 해당 칸의 도시 타일을 가져온 뒤 개인판 건물 보너스를 받고, 손패 운영 카드 1장을 설치해 상단 보너스만 받는다. 카드 하단 행동과 통상 턴 종료 카드 뽑기는 하지 않는다. 모두 준비를 마치면 본래 차례 순서의 첫 플레이어부터 1막을 시작한다. 근거: Rules v19c 6쪽 준비 라운드와 2인 부두 준비 문구. 개별 부두·건물·카드 보너스 값은 별도 catalog 확인 대상이다.

- 보드 고정 장부 목표: 부두는 상자 1/2/3개 목표마다 금고 $15, 시청은 서로 다른 구역 3/5/7곳에 보호 건물을 가진 목표마다 금고 $20, 악명은 10/15/22 이상에서 금고 $10/$15/$20이다. 수치는 최소 조건이며 초과해도 달성한다. 각 목표에는 장부 두 칸이 있고 한 플레이어는 같은 목표에 한 번만 배치한다. 고정 목표에는 별도 칸 보너스가 없다. 근거: Rules v19c 23쪽의 목표 설명과 부두·시청·악명 보드 그림. 타일 목표의 조건·칸 보너스는 별도 확인한다.

- 목표 배치: 섞은 지역 목표에서 맨 위를 다운타운에 놓고, 이미 놓인 목표와 번호가 다른 첫 타일들을 미드타운·업타운에 놓는다. 센트럴파크는 따로 섞은 A 묶음 맨 위 두 장, 이어서 기존 번호와 중복되지 않는 B 두 장, C 한 장을 왼쪽부터 놓는다. 건너뛴 타일과 남은 타일은 상자로 반환한다. 지역 목표와 센트럴파크의 번호 중복 검사는 각각 독립적이다. 근거: Rules v19c 5쪽 준비 항목 15–16. 목표 타일은 지역 9개·센트럴파크 21개이며(3쪽 구성물), 개별 조건·보너스와 묶음별 목록은 추가 확인이 필요하다.

- 지도 준비는 16개 구역(다운타운 1–6, 미드타운 7–12, 업타운 13–16)을 사용한다. 구역마다 건물 칸 2개이며 3–4인의 업타운만 3개다. 2인은 섞은 마피아 구역 타일을 순서대로 확인하여 다운타운 2·미드타운 2·업타운 1개를 폐쇄한다. 이미 목표 수를 채운 권역의 타일은 건너뛰며, 폐쇄된 다섯 구역만 마피아 구역 더미에서 제거한다. 나머지를 다시 섞어 초기 마피아 4개, 1–3막 2/2/3개를 배정한다. 3–4인은 폐쇄 없이 초기 6개, 1–3막 3/3/4개다. 초기 마피아는 해당 구역의 모든 건물 칸을 차지하며 공급된 A 타일의 세력을 사용한다. 경찰은 별도로 섞은 16개 구역을 초기 4개와 1–3막 각각 4개로 나눈다. 근거: Rules v19c 4–5쪽 준비 항목 3–12. 이 배치 절차의 확정은 마피아 개별 세력·효과나 지도 도로 연결의 확정을 뜻하지 않는다.

- 2인 폐쇄 구역에는 건물·마피아를 배치하지 않지만 경찰은 배치할 수 있다. 경찰 구역 타일을 폐쇄 구역 때문에 제외하거나 다시 뽑지 않는다. 근거: Rules v19c 4쪽 준비의 경찰 항목 10과 10쪽 경찰 진입 절차. 마피아 예정 구역의 폐쇄 여부와 경찰 예정 구역의 유효성을 별도로 검증한다.

- 4막, 플레이어 라운드 수 4/3/3/1. 준비는 역순, 본 게임은 차례 순서대로 진행한다. 1–3막 뒤 마피아 충돌 → 경찰 진입 → 지역 정산, 4막 뒤 최종 정산.
- 한 차례: 도우미 최대 1장 → 카포 배치와 그 자리의 행동 → 운영 카드 1장 가져오기. 장소 행동은 위에서 아래로, 같은 줄 안에서는 순서 선택. 레스토랑의 카드 버리기와 차례 변경은 필수다.
- 일반 행동 자리에는 카포 하나만 놓을 수 있고 해당 막 동안 점유한다. 레스토랑은 카포 수 제한이 없다. 1막 카포 4개로 시작하고, 다음 막 시작에 2막은 3개 회수/1개 제거, 3막은 3개 회수, 4막은 1개 회수/2개 제거한다. 근거: Rules v19c 8쪽.
- 차례 마지막에는 네 운영 덱 중 하나의 맨 위 카드 1장을 반드시 가져온다. 손패 제한은 없으며 버린 운영 카드는 같은 종류 덱의 맨 아래로 돌아간다. 근거: Rules v19c 8, 12쪽.
- 레스토랑에서는 운영 카드 1장을 버리고 아래 줄의 빈 차례 칸을 고른다. 2인은 두 번째, 3–4인은 세 번째/네 번째 칸에서 추가 1장을 버린다(3인은 네 번째 칸 사용 불가). 선택한 위치는 보호 영향력 계산에 즉시 적용하지만 실제 차례 순서는 라운드 종료 때 바뀐다. 근거: Rules v19c 19쪽.
- 레스토랑의 입장 처리 뒤에는 운영 카드 1장 사용·도시 타일 최대 2개 사용·장부 최대 3개 배치 중 서로 다른 두 행동을 원하는 순서로 고른다. 장소 행동은 입장 비용·차례 변경을 제외하면 선택 사항이므로 사용 없이 건너뛰는 선택도 허용한다. 장부는 하나씩 조건을 검사하고 보너스·금고 수익을 처리한다. 근거: Rules v19c 13, 19쪽.
- 운영 카드는 같은 종류의 기존 카드를 해당 덱 아래로 돌려놓고 새 카드를 설치한 뒤, 상단 보너스와 카드 행동 순서로 해결한다. 증류소에 보관한 주류는 교체 시 유지한다. 근거: Rules v19c 12쪽.
- 도시 타일은 레스토랑에서 최대 2개 사용하며, 그 행동 중 얻은 타일도 사용할 수 있다. 사용한 타일은 턴 종료에 중앙 열 3칸으로 반환한다. 남길 미사용 타일이 4개를 넘으면 플레이어가 초과분을 선택해 함께 반환한다. 반환은 빈칸부터 고르게 분배한다. 근거: Rules v19c 14, 19, 20, 24쪽과 FAQ.
- 전시장에서 가져올 수 있는 도시 타일은 덮이지 않은 앞면 타일뿐이다. 오른쪽 열에서 가져오면 뒤집힌 세 더미 중 하나의 맨 위 타일로 즉시 보충하며, 중앙 열은 보충하지 않는다. 근거: Rules v19c 5, 20쪽.
- 레스토랑 방문자가 있으면 라운드 종료 때 모든 플레이어가 영업 중인 카지노마다 현금 2인 $5, 3–4인 $3을 받는다. 기존과 같은 차례 위치를 골라도 지급한다. 이동하지 않은 차례 말은 상대 순서를 유지하며 빈칸을 채운다. 마지막 라운드에도 이 정산을 최종 점수보다 먼저 처리한다. 근거: Rules v19c 8, 19쪽과 FAQ.
- 건물 영업: 경찰이 없거나 조직원이 보호하면 영업한다. 경찰 진입은 기존 주류를 제거하지 않는다. 영업하지 않는 건물의 생산·운송·판매는 불가. 보호된 건물만 최종 건물 점수를 얻는다.
- 현금과 금고 분리. 금고로 비용 1을 충당하려면 금고 2를 지불한다. 타인에게 비용 1을 금고로 지불해도 상대는 현금 1만 받는다. 지불 출처를 선택할 수 있게 한다.
- 건설업자 사무소와 도시계획 사무소의 건설 행동은 각각 최대 2회이며 같은 방식 두 번 또는 서로 다른 방식을 선택할 수 있다. 각 건물마다 비용 지불 → 배치/인수/증축 → 해당 칸 도시 타일 획득(신규 배치/인수) → 개인판 보너스를 순서대로 처리한다. 근거: Rules v19c 14–15쪽. 개인별 자리의 전체 행동 구성과 개별 건물 보너스 값은 별도 확인 대상이다.
- 건축: 주점 $3/$5/$8, 증류소 $5. 주점은 해당 개인판 칸의 보너스와 연결된다. 나이트클럽 $12, 카지노 $17와 손패 운영 카드 1장. 한 구역권(Zone)에 자신의 나이트클럽·카지노 각각 최대 1개. 완전히 비운 주점 묶음으로 증축 할인 $3/$5/$8 중 최대값.
- 공격 성공은 공격력 > 방어력, 방어 성공은 방어력 ≥ 공격력. 조직원은 마피아 충돌의 방어력을 올리지 않는다. 동맹 마피아의 구역 주점은 인수할 수 없다. 부두 공격에는 동맹의 세력을 더하지 않는다.
- 트럭별 주류 2개, 영업 중인 자기 건물에 최대 1개 배달. 증류소에는 일반 배달 불가. 지도에 처음 진입은 무료, 이미 진입한 트럭은 지도를 나갈 수 없다. 중앙 공원을 가로질러 이동할 수 없다. 선박 1회 구매는 최대 2개이며 다음 빈 항구로 이동한다.
- 보호 행동당 사용 가능한 상시 영향력과 소비형 영향력을 구분한다. 상시 영향력은 행동 후 소멸하지 않으며 소비형 토큰만 소모한다.
- 운영 수준 5 진입은 손패의 운영 카드 1장을 버린다. 세력 4 진입은 1장, 5 진입은 2장을 버린다. 설치된 카드는 이 비용으로 버릴 수 없다. 악명은 다섯 수준의 합이며 증가 직후 도달한 칸의 보상을 처리한다. 근거: Rules v19c 12쪽. 개별 악명 보상은 별도 확인한다.
- 지역 지배는 보호 여부 우선, 그다음 카지노 > 나이트클럽 > 주점 > 증류소. 건물 수를 합산하지 않는다. 공동 지배 가능. 지역 정산은 마피아를 포함하며 동률은 해당 동률의 가장 낮은 등수 배당을 받는다.
- 목표마다 자기 장부는 최대 1개. 서로 다른 목표에는 같은 영역에도 여러 장부를 놓을 수 있다. 목표 종류별 조건은 원본 23쪽에 따른다.
- 마피아 충돌은 구역 번호 순서대로 한 마피아씩 공개하고 해당 구역의 방어를 끝낸 뒤 다음 마피아를 공개한다. 아직 공개하지 않은 세력을 미리 노출하지 않는다.
- 막 1/2/3의 신규 마피아 구역 수는 2인 2/2/3, 3–4인 3/3/4다. 신규 마피아는 빈 건물 칸을 채우고 차례순으로 각 플레이어 건물을 공격한다. 방어 시 사용한 부하·동맹 보정은 선택한 건물 하나에만 적용한다. 공격력은 기본 세력+충돌 보정이며, 이후 인수에 사용하는 구역 세력은 기본 세력이다. 빈 칸이 없고 모든 건물이 방어되어 주점을 전혀 놓지 못한 신규 마피아만 제거한다. 이전 막의 마피아는 그대로 남는다. 근거: Rules v19c 9–10쪽과 FAQ 1쪽.
- 모든 방어를 끝낸 뒤 예정된 경찰을 배치하고 영업 상태를 다시 계산하여 지역 배당을 **금고**에 지급한다. 경찰 진입으로 기존 주류가 사라지지 않는다. 근거: Rules v19c 10–11쪽과 FAQ.
- 최종 점수는 현금 + 금고 + 보호 건물(주점 10, 나이트클럽 15, 카지노/증류소 20) + 서로 다른 병의 도우미 점수. 동점은 보호 건물 수 → 전체 건물 수 → 배치 장부 수 → 남아 있는 조직원 수. 마지막까지 같으면 승자를 임의로 정하지 않는다.

## TO_BE_CONFIRMED — 구성물 데이터

규칙서는 종류와 처리 방법을 설명하지만 아래의 전체 개별 구성물 데이터를 명시적으로 열거하지 않는다. 이를 확인해야 자동 설정과 기본판 완주를 출시할 수 있다.

1. 운영 카드 48장의 종류별 12장 목록: 즉시 보너스, 영향력, 특수 효과, 중복 장수.
2. 마피아 타일 20장의 A/B/C/D 구분, 세력, 충돌 보정, 고용료, 동맹 효과 매핑.
3. 인원별 보드에서 빠지는 행동 자리, 정확한 지도 인접·항구 연결, 인쇄된 악명/운영/부두/건물 보너스와 지역 배당표.
4. 도우미 병 종류·점수 매핑, 도시 타일 54개의 효과별 장수, 목표 타일 칸의 보너스와 부두 선박 가격·방어력 표.
5. 마피아 주점은 24개로 한정된다(규칙서 3쪽). 필요한 배치 수보다 공급이 부족한 상태의 공식 진행 처리는 별도 확인한다. 개발 중 충돌 모듈은 이 경우 원본을 변경하지 않고 `CAPACITY`를 반환한다. 이는 출시 규칙이나 플레이어가 방어를 강요받는 변형 규칙이 아니다.

6. 도시 타일의 뒤집힌 보충 더미가 모두 소진된 상황에서 오른쪽 열 획득/보충 처리. 확인 전 개발 모듈은 보충할 수 없는 오른쪽 열 획득을 거절한다. 이는 확정된 출시 규칙이 아니다.

규칙서에 작은 그림으로 나온 값도 읽을 수 없는 부분은 추정하지 않는다. 원본 구성물 사진·공개 데이터·프로젝트 내 자료가 있으면 대조하여 이 목록을 줄인다. 테스트의 예시 값은 공식 구성물 데이터가 아니며 실제 대국 초기화에 사용하지 않는다.

## 온라인 정책 제안

시간 제한 없는 기본판, 연결 단절 시 선택 상태 유지, 명시적 나가기 시 해당 판 취소를 기본 설계로 한다. 서버 재시작을 넘는 영구 저장은 사용자의 요청으로 제외한다. 실제 대국 연결 시 room retention, host succession과 함께 검증한다. 솔로와 확장은 이번 기본판 범위에 포함하지 않는다.

2026-09-17 사용자가 “확인된 규칙으로 끝까지 진행되는 연습 대국” 제안에 개발 계속을 요청했다. 원작 기본판과 구별되는 **컴퓨터 상대 11턴 연습**을 먼저 제공한다. 정확한 연습 규칙은 `packages/shared/src/games/speakeasy/practice.ts`의 화면 안내와 일치한다. 공식 카드 효과·장수로 위장한 데이터를 사용하지 않으며 공식 솔로 모드도 아니다. 카포·카드·목표·마피아 충돌을 생략하고, 별도 행동 횟수·격자 지도·가격·초기 배치·경찰 일정·중간 수입으로 건설/생산/운송/판매/보호의 경제 흐름을 연습한다. 원작 기본판의 구성물 미확정 항목은 그대로 유지한다.
